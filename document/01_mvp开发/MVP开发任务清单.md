# MVP 开发任务清单

> 项目：《末法寻仙》  
> 类型：2D 修仙搜打撤 RPG  
> 文档版本：V0.1  
> 目标：完成一个可以验证核心玩法闭环的最小可行版本

---

## 一、MVP 目标

MVP 版本的目标不是做完整游戏，而是验证以下核心体验是否成立：

1. 玩家进入秘境前需要做资源准备。
2. 玩家在秘境中通过探索、战斗、搜刮获得资源。
3. 战斗会消耗灵力、属性石和武器耐久。
4. 背包空间有限，玩家需要做取舍。
5. 玩家需要判断继续深入还是撤离。
6. 成功撤离后，资源可以转化为修为、丹药或突破材料。
7. 玩家境界提升后，可进入更高阶秘境。

---

## 二、MVP 范围

### 1. 境界范围

MVP 只做：

- 炼气一层 ~ 炼气九层
- 筑基初期

暂不制作：

- 金丹
- 元婴
- 化神
- 领域系统
- 元婴出窍
- 高阶宗门玩法

---

### 2. 秘境范围

MVP 制作两个秘境：

| 秘境名称 | 定位 | 主要功能 |
| --- | --- | --- |
| 废弃灵田 | 新手秘境 | 教学、基础搜刮、低阶战斗 |
| 古宗外院 | 进阶秘境 | 筑基材料、精英怪、撤离压力 |

---

### 3. 武器范围

MVP 制作四种武器：

| 武器 | 定位 |
| --- | --- |
| 匕首 | 占格小，备用武器 |
| 长剑 | 均衡主武器 |
| 大刀 | 高伤害，占格大 |
| 法杖 | 基础伤害低，附魔收益高 |

---

### 4. 五行属性石范围

MVP 制作：

- 金属性石
- 木属性石
- 水属性石
- 火属性石
- 土属性石

等级只做：

- 1 级
- 2 级

纯度按四档处理：

| 纯度档位 | 范围 |
| --- | --- |
| 劣质 | 10%-49% |
| 普通 | 50%-69% |
| 精纯 | 70%-89% |
| 无瑕 | 90%-100% |

---

### 5. 成长范围

MVP 包含：

- 修为槽
- 天材地宝直接吞服
- 简单炼丹
- 炼气小境界提升
- 炼气突破筑基

暂不包含：

- 金丹品质
- 元婴机制
- 复杂心魔系统
- 领域系统

## 三、核心玩法闭环

```text

↓

提升境界
↓
挑战更高阶秘境
```

## 五、MVP 详细任务拆分

### 1. 角色系统

**需要实现：**

- 玩家生命值
- 玩家灵力值
- 玩家境界
- 玩家修为值
- 玩家死亡逻辑
- 玩家局外状态保存

**基础属性：**

| 属性 | 说明 |
| --- | --- |
| hp | 当前生命 |
| max_hp | 最大生命 |
| mp | 当前灵力 |
| max_mp | 最大灵力 |
| realm | 当前境界 |
| exp | 当前修为 |
| poison | 丹毒 |
| foundation | 根基稳定度 |

### 2. 战斗系统

**需要实现：**

- 普通攻击
- 武器伤害计算
- 怪物受伤
- 怪物死亡
- 怪物掉落
- 玩家受伤
- 玩家死亡
- 附魔攻击

**附魔攻击需要消耗：**

- 1 颗属性石
- 武器耐久

**附魔攻击产生：**

- 武器基础伤害
- 属性石附加伤害
- 五行效果
- 纯度效果

### 3. 武器系统

**需要实现：**

每把武器拥有：

| 属性 | 说明 |
| --- | --- |
| id | 武器 ID |
| name | 武器名称 |
| type | 武器类型 |
| base_damage | 基础伤害 |
| max_durability | 最大耐久 |
| durability | 当前耐久 |
| bag_width | 背包宽度 |
| bag_height | 背包高度 |

**MVP 规则：**

- 普通攻击不消耗耐久
- 附魔攻击消耗耐久
- 耐久为 0 后无法附魔
- 耐久为 0 后仍可普通攻击
- 撤离后可花费灵石修理

### 4. 五行附魔系统

**需要实现：**

- 五行属性石
- 属性石等级
- 属性石纯度档
- 附魔消耗
- 附魔伤害
- 五行效果

**MVP 附魔消耗：**

| 属性石等级 | 耐久消耗 |
| --- | --- |
| 1 级 | 5 |
| 2 级 | 6 |

**MVP 附魔伤害：**

| 属性石等级 | 附魔伤害 |
| --- | --- |
| 1 级 | +5 ~ +10 |
| 2 级 | +15 ~ +20 |

### 5. 背包系统

**需要实现：**

- 格子背包
- 物品占格
- 物品拾取
- 物品丢弃
- 物品堆叠
- 背包满时提示
- 撤离后保存背包收益

**MVP 背包建议：**

初始背包大小：

```text
6 × 5 = 30 格
```

### 6. 秘境系统

**需要实现：**

- 进入秘境
- 秘境地图
- 怪物生成
- 资源点生成
- 宝箱生成
- 撤离点生成
- 成功撤离
- 死亡结算

### 7. 炼丹系统

MVP 只做简单炼丹，不做复杂小游戏，只做配方合成。

**示例：**

```text
青玉灵果 + 低阶灵草 + 灵石 = 青玉培元丹
```

**炼丹结果：**

- 成功：获得丹药
- 失败：材料损失，获得药渣

### 8. 突破系统

**炼气突破筑基条件：**

| 条件 | 说明 |
| --- | --- |
| 炼气九层修为满 | 必须条件 |
| 筑基丹 | 必须材料 |
| 根基稳定度达标 | 影响品质 |
| 丹毒未超标 | 否则失败率提高 |

**筑基品质：**

| 品质 | 条件 |
| --- | --- |
| 残基 | 丹毒高、根基低 |
| 凡基 | 普通突破 |
| 灵基 | 根基较好 |
| 地基 | 根基优秀 |
| 天基 | 根基极佳且材料高品质 |

## 六、MVP 验收标准

完成 MVP 后，玩家应能完整体验：

1. 进入废弃灵田
2. 击败怪物获得属性石和灵草
3. 使用属性石给武器附魔
4. 附魔消耗武器耐久
5. 背包满后需要丢弃或取舍物品
6. 找到撤离点并成功撤离
7. 使用带出的天材地宝增加修为
8. 炼制丹药获得更高修为收益
9. 从炼气一层成长到炼气九层
10. 消耗筑基丹突破到筑基初期

---

## 七、MVP 暂不做内容

以下内容暂不进入第一版：

- 多人 PVP
- 宗门大战
- 金丹以上境界
- 元婴出窍
- 化神领域
- 复杂炼丹小游戏
- 法宝养成
- 洞府经营
- 大型剧情线
- 开放世界地图

---

## 八、开发建议顺序

建议按以下顺序开发：

1. 角色移动与基础交互
2. 背包格子系统
3. 物品拾取与掉落
4. 武器与基础攻击
5. 怪物 AI 与战斗
6. 属性石附魔
7. 武器耐久
8. 灵力与灵石恢复
9. 秘境进入与撤离
10. 死亡与结算
11. 吞服天材地宝
12. 简单炼丹
13. 境界突破
14. 第二个秘境
15. 数值调优
