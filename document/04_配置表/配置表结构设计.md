# 配置表结构设计

> 项目：《末法寻仙》  
> 文档版本：V0.1  
> 目标：为后续程序开发、数值配置、内容扩展提供基础数据结构

---

## 一、配置表总览

建议使用 CSV、Excel 或 JSON 管理配置。

初版至少需要以下配置表：

| 表名 | 用途 |
| --- | --- |
| realm_config | 境界配置 |
| weapon_config | 武器配置 |
| item_config | 通用物品配置 |
| element_stone_config | 五行属性石配置 |
| treasure_config | 天材地宝配置 |
| pill_config | 丹药配置 |
| alchemy_recipe_config | 炼丹配方配置 |
| monster_config | 怪物配置 |
| drop_config | 掉落配置 |
| dungeon_config | 秘境配置 |
| dungeon_resource_config | 秘境资源点配置 |
| bag_config | 背包配置 |

---

# 二、境界表 `realm_config`

## 1. 表用途

用于配置玩家不同境界阶段的属性、修为需求、解锁内容和突破条件。

---

## 2. 字段设计

| 字段名 | 类型 | 示例 | 说明 |
| --- | --- | --- | --- |
| realm_id | int | 1001 | 境界 ID |
| realm_name | string | 炼气一层 | 境界名称 |
| realm_type | string | 炼气 | 大境界类型 |
| stage | int | 1 | 小阶段 |
| need_exp | int | 100 | 升至下一阶段所需修为 |
| hp_add | int | 20 | 生命加成 |
| mp_add | int | 15 | 灵力加成 |
| atk_add | int | 2 | 攻击加成 |
| def_add | int | 1 | 防御加成 |
| unlock_system | string | enchant | 解锁系统 |
| breakthrough_item | string | none | 突破所需物品 |
| next_realm_id | int | 1002 | 下一境界 ID |
