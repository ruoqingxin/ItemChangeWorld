# 地图搜索撤离与计时

本篇首图参数不自动推广为所有忆境统一模板。

## 1. 地图骨架与规模

固定骨架加可选支路，不做全随机迷宫。常规完整路线八战，全图战斗节点最多十五战，首领计入总数；不是撤离前最低战数。

配比测试起点为常规六普通两精英，全图十一普通三精英一首领。首领在倒数第二个主节点，阻挡末撤离点；常规八战仍可不打首领完成。精确连线须提供可达性证明，不照搬旧八主路包含首领的脚手架。

首图需实际可遇至少三次途中借法台，起始另计，不能用互斥支路总数充数。第一台约两战后，其余分散中段深入段。中段可选支路一处悟道建筑，绕路后仍有战斗可用所得被动，同局只领一次。

独立搜索点三至五处为测试起点，与每敌战后箱分开计数。随机恢复节点一至两个，与搜索点分开。普通敌人覆盖消耗、蓄力、防御职责，精英增强一个机制，首领组合两个；保持一对一，不加召唤多敌人。

首领高风险、好物品概率更高，不保证特定技能书，也不保证所有构筑稳定击败。数值、掉落与首领道韵未定。

搜索点承担主要补给规划，战后少量随机补充。首段正常路线需有可预期的补给机会，但不保证每战掉药、每箱有药或精确缺什么补什么；具体数量随整局损耗测试。

## 2. 揭图、移动与直接入战

开局只显示前五个主节点，前进后逐步揭图；支路范围与每次新增数量待节点表。已揭示范围可显示连线、完成/可达状态、撤离、危险类别与奖励耗尽，不提前展示全图。

敌人节点仅显示普通、精英、首领类别，不透露具体敌人；战斗内仍可看当前意图。搜索前不透露物品名或结果。

沿实际连通路线移动，已通路线回退不限。路径上未击败敌人阻挡其后节点，不能点远端奖励或撤离点越过；已揭示不等于可达。其他合法支路可以选择，不要求清空全部分支。

点击可达未击败敌人直接进入战斗，无入战确认、无点击后取消窗口；物资在点击前战外整理。入战提交成功后不能回地图逃跑。完成节点可正常回退，不重开战斗、不重生敌人、不刷新物资。

## 3. 宝箱与搜索

每敌死亡掉一个宝箱，此时固定内容并保存，搜索只揭示，不重抽。独立搜索点同样固定结果并保存。

1. 未揭示物先黑影、转圈，逐件搜索；每件一秒为可调整测试起点。
2. 可随时中断，保留当前物品进度、已揭示、已拾取及剩余状态，重开续搜，不重播已完成部分。
3. 已揭示可先拿，未知物不能先拿或偷看名称；不做搜索失败概率，不反复要求点击同件物。
4. 关闭箱、离开节点、离线均不自动搜索，现实时间照常流逝。
5. 重复打开同一份箱，不复制或重复领取；满格处理和原节点返取见 [05](05_物品储物与终局结算.md)。

## 4. 恢复点

每处同局免费用一次，战外到点明确点击，预览实际恢复量，成功提交才扣机会。恢复血、蓝各自上限的 20%，不修耐久，不耗道具、不加长吟唱。

血蓝都满时禁用且不扣机会；仅一项不足可用，另一项溢出作废，不转盾、耐久或额度。回退、关闭、读档不刷新，恢复仍计时。具体恢复取整随事件/数值表提交。

## 5. 撤离与收尾

- 第一张图二至三撤离点，最后一处位置固定、被首领阻挡，其余一至两处位置随机，保留不打首领的正常撤离路线。选二或三的方法、位置池及权重待表。
- 战外到点确认即可，免费、无额外道具、撤离读条、撤离战或最低击杀数。
- 到点不自动结束，确认前说明保留、损失和临时构筑结束，取消可继续探索。
- 击败首领不自动撤离，可继续挑战其他敌人。全图处理完也不强制结束，需沿路线到撤离点。
- 正常战后先完成已触发强制被动选择，再开放地图/撤离；超时失败不补偿未完成构筑。
- 主动放弃须二次确认，按失败；战斗中不主动撤离或逃跑。关闭只是暂存，不等于放弃。

## 6. 二十分钟现实倒计时

必要资源局外预备，玩家确认入境且新局创建成功时记录起点和绝对截止，时限 1200 秒。起始抽道、主动选择、背包整理、阅读、广告、动画、后台和离线全部计入，不等技能选完才起算。

剩十分钟、五分钟各一行提示。首版无广告续时、临时加时、复活、死亡救援或超时宽限。

| 边界 | 结果 |
| --- | --- |
| 点击未超时，提交时达到或超过截止 | 先失败，本次结果无效，不部分扣资源或发奖励 |
| 主行动 | 临时状态算完整回合，校验和保存成功才算完成，提交前再查时间 |
| 独立用药已成功，之后主行动超时 | 已提交药品保留历史效果，主行动不提交，以此前有效状态失败结算 |
| 普通行动已提交，动画未完超时 | 整局失败，动画不暂停时间，不倒退已提交历史动作，不再允许搜箱/撤离 |
| 到撤离点或打开撤离确认 | 未结束本局，计时继续 |
| 撤离在截止前成功提交 | 结束计时，之后结果动画超时不反改失败 |
| 搜索、拾取、奖励、广告重抽提交 | 各自边界同样查截止，保存失败不能假报成功，已流逝时间不返还 |
| 恢复未结束同局 | 敌人、物品、随机候选与已完成动作不重生成，离线时间不退还 |

统一时间依据、防系统时间跳变、后台与多窗口方案交工程核对；本地单机不能承诺可信服务器级防篡改或跨端一致性。
