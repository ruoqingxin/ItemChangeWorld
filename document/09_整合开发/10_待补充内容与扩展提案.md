## 2. 土道包，已获准测试

| 部分 | 归并后的提案摘要 |
| --- | --- |
| 道性承岳 | 护盾实际吸收敌方意图直接伤害且存活，获得最多一份磐劲，强化紧接下一次主行动的直接攻击 |
| 磐劲限制 | 普攻或任一道攻击主动可兑现；非攻击主行动后失效，用药不消耗；不跨战、不按伤害段数累积、不响应持续伤害或反击 |
| 默认主动 | 飞岩术：低耗直接攻击；岩甲诀：花蓝获得高于通用防御的盾 |
| 书籍主动 | 撼岳击：持磐劲时本体增强；陷地术：较低攻击加当前意图有限减伤；返震印：盾实际吸伤后有限反击一次 |
| 默认被动 | 厚垒增强指定土道非攻击本体盾；砾锋增强磐劲普攻；迎险按当前危险意图给攻击主动小盾 |
| 书籍被动 | 重岳支持磐劲土道攻击；借山支持磐劲另一道攻击；固脉支持每场首次有效用药后的土道非攻击主动 |
| 强化方向 | 飞岩伤害、岩甲护盾，撼岳/陷地/返震交替强化两种本职，第五档双提升，不加行动/降耗/无限续盾 |

## 4. 高境界与十道方向，后置

筑基归锋剑、持锋及裂甲/回澜术式进阶暂缓，须先适配灵力，不抄旧剑势门槛。高境界不机械填同数量技能或固定每境界加一剑势。

| 大道 | 原草案玩法方向，不是已批准技能 |
| --- | --- |
| 时间 | 有限回响、延后生效与兑现时点 |
| 空间 | 隔绝、封存、效果转移，不引入自由移动 |
| 剑 | 已确认炼气内容按第 04 篇，其余分支继续设计 |
| 魂 | 魂痕与特定意图窗口 |
| 土 | 防守转反攻，具体按本篇待批包 |
| 清浊 | 本源专题，排除普通随机池，能力设明确上限 |
| 丹 | 有代价的药性配合与补给时机 |
| 阵 | 行动次序、阵纹与预先布局，作为下一轮扩展 |
| 冰 | 有限压制危险出手，与时间/魂区分 |
| 体 | 承担风险后反攻，权衡血量与行动 |

不得用回响复制真实库存、以丹/体无成本无限回满、以魂/冰无限锁敌。至强尊号与背景只作原文追溯，不把游戏技能创作冒称小说记载。

旧宗门/黑市/洞府、炼丹配方/丹毒根基、装备词条/属性石合成、高阶领域与特殊撤离等完整保存在历史原稿，只是未来候选，不进入首版必做，也不以本次整合批准实现。
