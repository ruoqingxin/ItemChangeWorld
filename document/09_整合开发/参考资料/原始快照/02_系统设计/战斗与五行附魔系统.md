# 战斗与五行附魔系统

> 项目：《末法寻仙》  
> 文档版本：V0.1  
> 目标：定义战斗资源、武器耐久、五行附魔和伤害计算规则

---

## 一、系统定位

战斗系统围绕以下核心展开：

> **武器耐久 + 五行附魔 + 灵力消耗 + 背包资源管理**

玩家不是单纯依靠角色面板战斗，而是依靠本局携带的资源进行决策。

每次战斗都要考虑：

- 是否值得消耗灵力？
- 是否值得使用属性石？
- 是否值得消耗武器耐久？
- 是否继续深入？
- 是否保留高纯属性石给精英怪？
- 武器耐久不足时是否撤离？

---

# 二、战斗资源

| 资源 | 作用 |
| --- | --- |
| 生命 | 归零死亡 |
| 灵力 | 使用技能、身法、法器消耗 |
| 灵石 | 回复灵力，也可激活撤离阵法 |
| 武器耐久 | 附魔会消耗耐久 |
| 属性石 | 提供附魔伤害和五行效果 |
| 丹药 | 回复、临时强化、清毒等 |

# 三、基础战斗规则

## 1. 普通攻击

普通攻击使用当前武器的基础伤害。

MVP 规则：

```text
普通攻击不消耗武器耐久。
```

普通攻击适用于：

- 清理弱小怪物
- 节省属性石
- 武器耐久不足时保底输出

## 2. 附魔攻击

附魔攻击需要消耗：

- 1 颗五行属性石
- 武器耐久

附魔攻击获得：

- 武器基础伤害
- 属性石附加伤害
- 五行效果
- 纯度额外效果
- 五行克制修正

## 3. 技能攻击

MVP 可先简化：

- 技能消耗灵力
- 技能可与附魔系统暂时分离
- 后续版本再考虑技能是否能附魔

# 四、武器系统

## 1. 武器基础属性

| 属性 | 说明 |
| --- | --- |
| 武器类型 | 匕首、长剑、大刀、法杖等 |
| 基础伤害 | 普通攻击造成的基础伤害 |
| 最大耐久 | 武器最大耐久 |
| 当前耐久 | 当前剩余耐久 |
| 占格大小 | 在背包中占用格子 |
| 附魔适性 | 影响附魔收益，MVP 可固定为 1.0 |

## 2. MVP 武器类型

| 武器 | 占格 | 基础伤害 | 耐久 | 特点 |
| --- | --- | --- | --- | --- |
| 匕首 | 1×2 | 12 | 30 | 占格小，适合备用 |
| 长剑 | 1×4 | 20 | 50 | 均衡主武器 |
| 大刀 | 2×4 | 32 | 55 | 伤害高，占格大 |
| 法杖 | 1×4 | 14 | 45 | 附魔效率高 |

## 3. 耐久规则

MVP 规则：

- 普通攻击不消耗耐久
- 附魔攻击消耗耐久
- 耐久不足时不能附魔
- 耐久归零后进入"灵纹破损"状态
- 灵纹破损状态下只能普通攻击
- 撤离后可花费灵石修理

## 4. 耐久状态

| 耐久比例 | 状态 | 效果 |
| --- | --- | --- |
| 70%-100% | 完好 | 正常使用 |
| 30%-69% | 磨损 | 可正常附魔 |
| 1%-29% | 残损 | 可附魔，但 UI 提示风险 |
| 0% | 灵纹破损 | 无法附魔，只能基础攻击 |

# 五、五行属性石

## 1. 属性石维度

五行属性石拥有：

| 维度 | 说明 |
| --- | --- |
| 五行类型 | 金、木、水、火、土 |
| 等级 | 1-3 级，MVP 先做 1-2 级 |
| 纯度 | 10%-100%，按区间结算 |

## 2. 五行类型

| 五行 | 配置值 | 战斗定位 |
| --- | --- | --- |
| 金 | metal | 破甲、暴击 |
| 木 | wood | 中毒、续航 |
| 水 | water | 减速、控制 |
| 火 | fire | 灼烧、爆发 |
| 土 | earth | 护盾、破韧 |

## 3. 属性石等级伤害

| 等级 | 附魔伤害 | 耐久消耗 |
| --- | --- | --- |
| 1级 | +5 ~ +10 | 5 |
| 2级 | +15 ~ +20 | 6 |
| 3级 | +25 ~ +30 | 8 |

MVP 先使用：

- 1 级
- 2 级

## 4. 纯度档位

| 档位 | 纯度范围 | 效果 |
| --- | --- | --- |
| 劣质 | 10%-49% | 无额外效果 |
| 普通 | 50%-69% | 轻微五行效果 |
| 精纯 | 70%-89% | 轻微五行效果 + 强化触发 |
| 无瑕 | 90%-100% | 轻微效果 + 强化触发 + 高纯效果 |

# 六、五行效果

## 1. 轻微效果

| 五行 | 轻微效果 |
| --- | --- |
| 金 | 流血，每秒造成少量伤害，持续 2 秒 |
| 木 | 中毒，每秒造成少量伤害，持续 3 秒 |
| 水 | 减速，降低敌人移动速度，持续 2 秒 |
| 火 | 灼烧，每秒造成少量伤害，持续 2 秒 |
| 土 | 破韧，降低敌人短时间防御 |

## 2. 强化触发

| 五行 | 强化触发 |
| --- | --- |
| 金 | 小概率本次附魔伤害翻倍 |
| 木 | 小概率恢复玩家少量生命 |
| 水 | 小概率冻结敌人 1 秒 |
| 火 | 小概率爆燃，造成额外范围伤害 |
| 土 | 小概率眩晕敌人 1 秒 |

## 3. 高纯效果

| 五行 | 高纯效果 |
| --- | --- |
| 金 | 忽略敌人 10% 防御 |
| 木 | 降低敌人 10% 恢复效果 |
| 水 | 降低敌人 10% 闪避或速度 |
| 火 | 忽略敌人 10% 火抗 |
| 土 | 本次攻击后获得少量护盾 |

# 七、五行克制

## 1. 克制关系

- 金克木
- 木克土
- 土克水
- 水克火
- 火克金

## 2. 战斗倍率

| 关系 | 效果 |
| --- | --- |
| 克制敌方属性 | 附魔伤害 × 1.2 |
| 被敌方克制 | 附魔伤害 × 0.8 |
| 同属性 | 附魔伤害 × 0.9 |
| 无关系 | 附魔伤害 × 1.0 |

# 八、伤害公式

## 1. 普通攻击公式

```text
普通伤害 = max(1, 武器基础伤害 + 玩家攻击 - 敌方防御)
```

## 2. 附魔攻击公式

```text
附魔基础伤害 = 武器基础伤害 + 玩家攻击 + 属性石附魔伤害

防御后伤害 = max(1, 附魔基础伤害 - 敌方防御)

最终伤害 = 防御后伤害 × 五行克制倍率
```

## 3. 示例

玩家使用长剑：

```text
武器基础伤害 = 20
玩家攻击 = 5
敌方防御 = 3
属性石 = 1级火属性石
附魔伤害 = 8
敌方属性 = 金
火克金，倍率 = 1.2
```

计算：

```text
附魔基础伤害 = 20 + 5 + 8 = 33
防御后伤害 = 33 - 3 = 30
最终伤害 = 30 × 1.2 = 36
```

本次攻击造成：

```text
36 点伤害
并触发火属性纯度对应效果
```

# 九、附魔操作流程

## 1. 玩家操作流程

```text
选择武器
↓
选择属性石
↓
点击附魔攻击 / 快捷键释放
↓
检查武器耐久是否足够
↓
检查属性石是否存在
↓
扣除属性石
↓
扣除武器耐久
↓
计算伤害
↓
触发五行效果
```

## 2. 附魔失败情况

以下情况无法附魔：

| 情况 | 提示 |
| --- | --- |
| 武器耐久不足 | 武器灵纹破损，无法承载附魔 |
| 没有属性石 | 缺少五行属性石 |
| 武器不存在 | 未装备武器 |
| 当前状态不可攻击 | 眩晕、死亡、硬直中 |

# 十、平衡原则

## 1. 普攻与附魔关系

- 普攻用于清理小怪
- 附魔用于精英怪、Boss、高威胁敌人
- 普攻不能完全无用
- 附魔不能无脑常开

## 2. 耐久压力

建议一把长剑满耐久可支持：

```text
8-10 次 1 级附魔攻击
```

即：

```text
50 耐久 / 每次 5 耐久 = 10 次
```

这样玩家必须节制使用。

## 3. 属性石掉落

建议单局废弃灵田平均产出：

```text
2-5 颗 1 级属性石
```

让玩家有资源使用，但不能无限滥用。

# 十一、UI 需求

## 1. 战斗界面需要显示

- 当前生命
- 当前灵力
- 当前武器
- 武器耐久
- 当前选中属性石
- 属性石数量
- 敌人五行属性
- 敌人生命

## 2. 附魔提示

当玩家选择属性石时，显示：

```text
火属性石 1级 精纯
附魔伤害：+5~10
耐久消耗：5
效果：灼烧 + 小概率爆燃
```

## 3. 耐久警告

当武器耐久低于 30%：

```text
武器灵纹不稳，继续附魔可能导致武器失效。
```

当耐久为 0：

```text
武器灵纹破损，无法继续附魔。
```
