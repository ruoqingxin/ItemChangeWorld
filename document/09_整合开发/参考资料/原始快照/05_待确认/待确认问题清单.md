# 待确认问题清单

> 项目：《末法寻仙》  
> 文档版本：V0.1  
> 用途：记录当前设计中仍需拍板的问题

## 一、战斗相关

### 1. 战斗形式

当前未最终确定：

- 回合制
- 半即时制
- 即时制

**建议：**

```text
如果是独立开发，优先考虑半即时制或轻量即时制。
```

**待确认：**

```text
最终战斗类型：？
```

### 2. 附魔持续方式

**当前建议：**

```text
一颗属性石 = 一次附魔攻击
```

**可选方案：**

| 方案 | 优点 | 缺点 |
| --- | --- | --- |
| 一次攻击消耗一颗 | 简单直接 | 操作频繁 |
| 附魔持续多次攻击 | 操作轻松 | 数值更难平衡 |
| 附魔持续一段时间 | 适合即时战斗 | 资源消耗不直观 |

**待确认：**

```text
附魔持续方式：？
```

### 3. 普通攻击是否消耗耐久

**当前建议：**

```text
MVP 中普通攻击不消耗耐久。
```

**后续可选：**

```text
普通攻击少量消耗耐久。
```

**待确认：**

```text
普通攻击是否消耗耐久：？
```

### 4. 技能是否可以附魔

**MVP 建议：**

```text
技能暂不参与附魔。
```

**后续可做：**

```text
技能可消耗属性石触发元素强化。
```

**待确认：**

```text
技能是否可附魔：？
```

## 四、成长相关

### 1. 局内是否允许突破

**可选：**

| 方案 | 说明 |
| --- | --- |
| 不允许 | 只能撤离后突破，更稳 |
| 允许小境界突破 | 增加局内爽点 |
| 允许大境界突破 | 风险高，仪式感强 |

**MVP 建议：**

```text
局内允许吞服增加修为，但突破只能局外进行。
```

**待确认：**

```text
局内是否允许突破：？
```

### 2. 丹毒阈值

需要确定：

- 丹毒多少算安全？
- 丹毒多少影响突破？
- 丹毒多少禁止突破？

**建议初版：**

| 丹毒 | 状态 |
| --- | --- |
| 0-30 | 安全 |
| 31-60 | 轻微影响 |
| 61-80 | 明显影响 |
| 81+ | 不建议突破 |

**待确认：**

```text
丹毒阈值：？
```

### 3. 炼丹是否有失败率

**MVP 建议：**

```text
有简单失败率。
```

**失败结果：**

- 材料损失

**待确认：**

```text
炼丹是否有失败率：？
```
