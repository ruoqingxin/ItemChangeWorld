# 一、游戏基础定位

## 1. 游戏类型

**2D 修仙题材搜打撤 RPG**

核心玩法融合：

- 修仙境界成长
- 秘境探索
- 搜打撤撤离机制
- 背包格子管理
- 武器耐久消耗
- 五行临时附魔
- 天材地宝吞服 / 炼丹成长
- 灵石补充灵力
- 高风险高收益资源争夺

---

## 2. 核心一句话

玩家处于一个灵气枯竭的末法时代，无法靠打坐自然修炼，只能进入危险秘境搜集天材地宝，以灵石维持战斗灵力，在有限背包和高风险战斗中做出取舍，最终将带出的资源转化为修为、丹药与突破资粮。

---

## 3. 游戏核心体验

玩家每次进入秘境，都会面对几个关键问题：

- 我要带多少武器？
- 我要带多少灵石补充灵力？
- 我要带多少属性石用于附魔？
- 我要带多少丹药和应急补给？
- 搜到天材地宝后，是现场吞服，还是带出去炼丹？
- 武器耐久快没了，是继续深入，还是撤离？
- 背包满了，应该丢掉什么？
- 遇到精英怪，是消耗资源击杀，还是绕开？
- 这次撤离收益够不够支撑下一次突破？

核心体验是：

> **冒险、搜刮、取舍、撤离、炼化、突破。**

---

## 4. 核心设计方向

本游戏强调：

| 方向 | 说明 |
| --- | --- |
| 资源消耗 | 战斗不是无成本行为，灵力、灵石、耐久、属性石都会被消耗 |
| 高风险收益 | 越深入秘境，收益越高，但撤离风险也越大 |
| 背包取舍 | 玩家需要在战斗资源和战利品空间之间做选择 |
| 修仙成长 | 成长不靠打怪经验，而靠天材地宝、丹药和突破资粮 |
| 境界解锁 | 境界不仅提升数值，还解锁秘境、能力和玩法机制 |
| 五行策略 | 通过五行附魔、属性克制和纯度效果形成战斗策略 |

# 二、世界观背景设定

## 1. 时代背景：末法时代

上古时期，天地灵气充盈，修士可通过吐纳、闭关、悟道自然增长修为。

但一场上古大劫之后：

- 天地灵脉断裂
- 洞天福地崩塌
- 灵气逐渐枯竭
- 凡世已经无法支撑正常修炼
- 普通修士打坐只能恢复精神，不能增长修为

因此，如今的修士已经无法通过普通修炼提升境界。

---

## 2. 秘境成为唯一修行来源

虽然外界灵气枯竭，但一些上古秘境、残破洞天、古宗遗址中仍残留旧时代灵机。

这些地方存在：

- 天材地宝
- 古修丹药
- 妖兽内丹
- 五行属性石
- 灵脉残片
- 古宗传承
- 突破所需的稀有资粮

因此，修仙世界变成了一个残酷的资源争夺场。

---

## 3. 修士现状

末法时代的修士不再是安稳闭关的修行者，而更像是冒险者、掠夺者、探索者。

他们为了突破境界，必须进入秘境：

- 搜刮资源
- 猎杀妖兽
- 破解禁制
- 抢夺机缘
- 活着撤离

修仙不再是"静修"，而是"争命"。

---

## 4. 世界观核心矛盾

本世界的核心矛盾是：

> **修士无法自然修炼，但仍然渴望长生。**

由此产生：

- 宗门争夺秘境入口
- 散修冒死探索遗迹
- 黑市交易天材地宝
- 修士之间杀人夺宝
- 各势力垄断突破材料
- 炼丹师和阵法师地位上升

# 三、核心玩法循环

## 1. 局外循环

```text
整理背包
↓
准备武器、灵石、属性石、丹药
↓
选择秘境
↓
进入副本
↓
探索、搜索、战斗、搜刮
↓
判断继续深入或撤离
↓
成功撤离，带出资源
↓
吞服 / 炼丹 / 出售 / 突破
↓
强化角色，开启更高阶秘境
```

## 2. 局内循环

```text
进入秘境
↓
探索房间 / 区域
↓
发现怪物、宝箱、草药、禁制
↓
战斗或绕开
↓
获得掉落
↓
背包取舍
↓
灵力、武器耐久、补给持续消耗
↓
寻找撤离点
↓
成功撤离或死亡损失
```

## 3. 核心资源压力

局内主要压力来自 5 个方面：

| 压力类型 | 说明 |
| --- | --- |
| 生命压力 | 血量耗尽会死亡 |
| 灵力压力 | 技能、法器、身法、战斗行为消耗灵力 |
| 灵石压力 | 灵石用于补充灵力，也可作为局内货币或阵法启动资源 |
| 武器耐久压力 | 附魔会消耗武器耐久，耐久归零后无法附魔 |
| 背包空间压力 | 武器、灵石、属性石、天材地宝都占空间 |

# 四、角色成长设定

## 1. 成长核心原则

本游戏不采用传统"打怪升级"。

玩家无法通过普通战斗直接获得境界经验。

境界成长主要来自：

- 天材地宝
- 妖丹
- 灵液
- 古修丹药
- 炼丹产物
- 秘境特殊资源
- 突破材料

## 2. 修为来源

玩家获得修为的方式主要有两种：

### 方式一：直接吞服

玩家在秘境中获得天材地宝后，可以直接吞服。

**优点：**

- 立即获得修为
- 局内可临时变强
- 紧急情况下可救命
- 不需要撤离后加工

**缺点：**

- 转化效率较低
- 增加丹毒 / 杂质
- 可能影响根基
- 高阶材料低境界强吞可能造成反噬

### 方式二：带出炼丹

玩家成功撤离后，可将材料带回局外炼制丹药。

**优点：**

- 修为转化效率更高
- 丹毒更低
- 有概率获得高品质丹药
- 对突破品质更友好

**缺点：**

- 必须成功撤离
- 炼丹可能失败
- 需要丹方、丹炉、辅材
- 消耗时间或灵石

## 3. 成长公式建议

角色成长可以理解为：

```text
最终成长 = 修为积累 × 根基质量 × 突破品质
```

其中：

| 维度 | 说明 |
| --- | --- |
| 修为积累 | 通过吞服、炼丹、秘境资源获得 |
| 根基质量 | 受丹毒、杂质、突破准备影响 |
| 突破品质 | 决定新境界的属性倍率和后续上限 |

## 4. 丹毒、杂质与根基

为了避免玩家无脑吞服所有资源，加入以下限制：

| 系统 | 说明 |
| --- | --- |
| 丹毒 | 直接吞服和频繁服丹会增加丹毒，影响突破成功率 |
| 杂质 | 低品质资源会增加修为杂质，影响根基质量 |
| 根基 | 决定突破品质、属性倍率和后续潜力 |

# 五、境界系统设定

## 1. 初版境界数量

建议第一版先做 5 个大境界：

- 炼气
- 筑基
- 金丹
- 元婴
- 化神

每个大境界可拆成小阶段：

- 初期
- 中期
- 后期
- 圆满

或者炼气境可做成：

- 炼气一层到九层

## 2. 境界作用

境界不只是数值等级，还承担以下功能：

| 功能 | 说明 |
| --- | --- |
| 数值成长 | 提高生命、灵力、攻击、防御等基础属性 |
| 玩法解锁 | 解锁炼丹、神识、领域、法宝等系统 |
| 地图准入 | 决定能进入哪些秘境区域 |
| 环境适应 | 决定能否承受秘境中的威压、毒瘴、阴煞等 |
| 身份变化 | 境界影响宗门、NPC、黑市对玩家的态度 |
| 撤离能力 | 高境界可使用更高级的撤离方式 |

## 3. 境界与秘境准入

| 境界 | 可进入秘境 |
| --- | --- |
| 炼气 | 废弃灵田、低阶洞府外围 |
| 筑基 | 古宗外院、地脉浅层 |
| 金丹 | 古宗内殿、地脉裂谷 |
| 元婴 | 魂域秘境、残破洞天 |
| 化神 | 法则裂隙、上古战场深处 |

# 六、大境界详细设计

## 1. 炼气境

### 世界观定位

炼气境不是从天地中吸收灵气，而是学会容纳、转化、使用外来灵力。

末法时代下，炼气修士必须依靠灵石、灵草、低阶丹药维持修行。

### 游戏定位

新手阶段。

玩家在这个阶段学习：

- 基础移动
- 基础战斗
- 搜索资源
- 使用灵石恢复灵力
- 武器附魔
- 背包取舍
- 撤离机制

### 核心玩法

- 低阶秘境探索
- 基础妖兽战斗
- 采集低阶灵草
- 使用 1 级属性石
- 学会撤离

### 可用资源

- 低阶灵草
- 聚气散
- 1 级属性石
- 劣品灵石
- 残缺妖丹

### 突破到筑基条件

| 条件 | 说明 |
| --- | --- |
| 修为圆满 | 当前境界修为槽填满 |
| 筑基材料 | 筑基玉液、筑基丹、地脉玉髓等 |
| 根基稳定 | 丹毒、杂质不能过高 |
| 筑基试炼 | 完成一次突破事件或战斗 |

### 核心体验

活着带出资源，比杀死所有敌人更重要。

## 2. 筑基境

### 世界观定位

筑基是修士第一次真正建立稳定修行体系。

末法时代的筑基，本质是把外来资源强行转化为自身根基。

### 游戏定位

第一个流派分化阶段。

玩家开始选择自己的战斗方向：

- 剑修
- 法修
- 体修
- 符修
- 丹修

### 核心玩法

- 解锁中阶秘境
- 解锁更多武器类型
- 解锁 2 级属性石
- 开始出现流派技能
- 可使用更稳定的灵石恢复方式

### 筑基品质

筑基时根据玩家准备程度，生成筑基品质。

| 品质 | 效果 |
| --- | --- |
| 残基 | 属性较低，后续突破难度增加 |
| 凡基 | 普通筑基 |
| 灵基 | 灵力上限提高 |
| 地基 | 灵石转化效率提高 |
| 天基 | 附带特殊被动，后续潜力最高 |

### 突破到金丹条件

| 条件 | 说明 |
| --- | --- |
| 修为圆满 | 筑基修为满 |
| 凝丹主材 | 结丹灵引、妖丹精华等 |
| 心境试炼 | 击败心魔或完成事件 |
| 根基稳定 | 根基越好，金丹品质越高 |

## 3. 金丹境

### 世界观定位

金丹境是将庞杂修为凝成稳定核心。

玩家不再只是堆资源，而是将资源压缩、提纯、内化。

### 游戏定位

中期 Build 成型阶段。

### 核心玩法

- 解锁高级炼丹
- 解锁本命法宝雏形
- 解锁丹火
- 可挑战高价值精英区域
- 可使用 3 级属性石

### 金丹品质

| 品质 | 说明 |
| --- | --- |
| 杂丹 | 资源驳杂，成长较差 |
| 真丹 | 标准金丹 |
| 灵丹 | 灵力循环更顺 |
| 地丹 | 防御、续航更强 |
| 天丹 | 神通槽位增加 |
| 无瑕金丹 | 最高品质，后续元婴成功率提高 |

### 突破到元婴条件

| 条件 | 说明 |
| --- | --- |
| 修为圆满 | 金丹修为满 |
| 婴变材料 | 婴胎石、养魂花等 |
| 神魂强度 | 需要魂类资源培养 |
| 心魔关 | 必须完成一次高风险试炼 |

## 4. 元婴境

### 世界观定位

元婴境代表神魂具象化。

修士不再完全依赖肉身，可短暂神识离体，感知秘境深层信息。

### 游戏定位

中后期机制质变阶段。

### 核心玩法

- 神识探测宝物
- 探测敌人位置
- 短暂元婴出窍
- 识破幻阵和伪装
- 开启特殊撤离方式

### 搜打撤特色能力

| 能力 | 作用 |
| --- | --- |
| 神识探宝 | 感知附近高价值资源 |
| 魂体穿行 | 短时间穿过特殊障碍 |
| 神识预警 | 提前感知精英怪或埋伏 |
| 元婴遁逃 | 死亡时有概率保留部分收益 |

### 突破到化神条件

| 条件 | 说明 |
| --- | --- |
| 修为圆满 | 元婴修为满 |
| 化神引 | 高阶秘境稀有掉落 |
| 法则碎片 | 特殊区域获取 |
| 大型试炼 | 完成一次化神级突破事件 |

## 5. 化神境

### 世界观定位

化神修士可以短暂影响周围规则，在末法环境中形成自身领域。

### 游戏定位

后期高级玩法。

### 核心玩法

- 领域系统
- 法相技能
- 高阶秘境探索
- 规则压制
- 特殊撤离干涉

### 领域效果示例

| 领域类型 | 效果 |
| --- | --- |
| 金行领域 | 提高破甲和暴击 |
| 木行领域 | 持续恢复，削弱敌方恢复 |
| 水行领域 | 减速、冻结、降低敌方行动 |
| 火行领域 | 持续灼烧，爆发提高 |
| 土行领域 | 护盾、减伤、破韧 |

# 七、战斗系统设定

## 1. 战斗核心定位

战斗系统围绕：

**武器耐久 + 五行附魔 + 灵力消耗 + 背包资源管理**

展开。

玩家的战斗力不是固定数值，而取决于本局携带的资源和战斗中的取舍。

## 2. 战斗资源

| 资源 | 作用 |
| --- | --- |
| 生命 | 归零死亡 |
| 灵力 | 使用技能、法器、身法消耗 |
| 灵石 | 回复灵力，也可激活阵法 / 撤离点 |
| 武器耐久 | 决定武器是否能承载附魔 |
| 属性石 | 提供五行附魔伤害和特殊效果 |

## 3. 武器系统

每件武器拥有以下基础属性：

| 属性 | 说明 |
| --- | --- |
| 武器类型 | 剑、刀、枪、杖、弓、拳套等 |
| 占格大小 | 背包占用空间 |
| 基础伤害 | 不附魔时造成的基础伤害 |
| 最大耐久 | 武器最大可承受损耗 |
| 当前耐久 | 当前剩余耐久 |
| 附魔适性 | 可选字段，影响附魔收益 |

## 4. 武器占格设计

| 武器 | 占格 | 特点 |
| --- | --- | --- |
| 匕首 | 1×2 | 占格小，适合备用 |
| 短剑 | 1×3 | 灵活均衡 |
| 长剑 | 1×4 | 标准主武器 |
| 大刀 | 2×4 | 高伤害，占格大 |
| 长枪 | 1×5 | 攻击距离长，耐久较高 |
| 法杖 | 1×4 | 基础伤害低，附魔效率高 |
| 重锤 | 2×3 | 高破防，高耐久 |
| 拳套 | 2×2 | 多段攻击，附魔消耗频繁 |

## 5. 武器耐久规则

初版建议：

- 普通攻击不消耗耐久
- 附魔攻击消耗耐久
- 耐久不足时不能附魔
- 耐久为 0 时进入"灵纹破损"状态
- 灵纹破损后仅保留基础伤害
- 灵纹破损武器撤离后可修复

### 耐久状态

| 耐久比例 | 状态 | 效果 |
| --- | --- | --- |
| 70%-100% | 完好 | 正常使用 |
| 30%-69% | 磨损 | 可正常附魔 |
| 1%-29% | 残损 | 可附魔，但建议 UI 提醒 |
| 0% | 灵纹破损 | 无法附魔，只能基础攻击 |

# 八、五行附魔系统

## 1. 基础规则

玩家可在攻击前消耗一颗五行属性石，对武器进行一次临时附魔。

每次附魔会消耗：

- 1 颗属性石
- 一定武器耐久

附魔后本次攻击获得：

- 额外属性伤害
- 五行特殊效果
- 可能触发纯度额外效果

## 2. 属性石维度

五行属性石拥有 3 个核心维度：

| 维度 | 说明 |
| --- | --- |
| 五行类型 | 金、木、水、火、土 |
| 等级 | 1-3 级，决定基础附魔伤害 |
| 纯度 | 10%-100%，决定额外效果 |

## 3. 属性石等级效果

| 等级 | 附魔基础伤害 | 推荐区域 |
| --- | --- | --- |
| 1级 | +5 ~ +10 | 炼气秘境 |
| 2级 | +15 ~ +20 | 筑基秘境 |
| 3级 | +25 ~ +30 | 金丹及以上秘境 |

## 4. 属性石纯度效果

建议按区间结算，降低复杂度。

| 纯度 | 品质名 | 效果 |
| --- | --- | --- |
| 10%-49% | 劣质 | 无额外效果 |
| 50%-69% | 普通 | 触发轻微五行效果 |
| 70%-89% | 精纯 | 轻微五行效果 + 强化触发 |
| 90%-100% | 无瑕 | 轻微效果 + 强化触发 + 高纯效果 |

## 5. 五行效果定位

| 五行 | 定位 | 轻微效果 | 强化触发 | 高纯效果 |
| --- | --- | --- | --- | --- |
| 金 | 破甲 / 暴击 | 流血 | 小概率伤害翻倍 | 忽略部分防御 |
| 木 | 毒 / 续航 | 中毒 | 小概率吸血 | 降低敌方恢复 |
| 水 | 减速 / 控制 | 减速 | 小概率冻结 | 降低敌方闪避 |
| 火 | 灼烧 / 爆发 | 灼烧 | 小概率爆燃 | 忽略部分火抗 |
| 土 | 护盾 / 破韧 | 降攻 / 破韧 | 小概率眩晕 | 获得护盾 |

## 6. 附魔耐久消耗

初版建议简单处理：

| 属性石等级 | 附魔消耗耐久 |
| --- | --- |
| 1级 | 5 |
| 2级 | 6 |
| 3级 | 8 |

## 7. 五行克制

建议第一版加入，但数值不要过高。

### 克制关系

- 金克木
- 木克土
- 土克水
- 水克火
- 火克金

### 战斗效果

| 关系 | 效果 |
| --- | --- |
| 克制敌方属性 | 附魔伤害 +20% |
| 被敌方克制 | 附魔伤害 -20% |
| 同属性 | 附魔伤害 -10% |
| 无关系 | 正常伤害 |

## 8. 附魔伤害公式

初版公式：

```text
最终伤害 = 武器基础伤害 + 属性石附魔伤害 + 纯度加成 - 敌方防御
```

如果有五行克制：

```text
最终伤害 = （武器基础伤害 + 属性石附魔伤害 + 纯度加成 - 敌方防御）× 五行克制倍率
```

# 十四、死亡与损失设定

## 1. 死亡基础规则

玩家在秘境中死亡后：

- 本局未绑定物资大部分掉落
- 背包内资源损失
- 当前局收益无法完整带出
- 已消耗灵石、属性石、耐久不返还

## 2. 保底机制

为了降低挫败感，建议保留：

| 保留内容 | 说明 |
| --- | --- |
| 地图见闻 | 探索过的部分情报保留 |
| 图鉴 | 见过的怪物、材料记录 |
| 丹方 | 已学会丹方不丢 |
| 已吞服少量修为 | 可保留一部分 |
| 局外仓库物品 | 不受影响 |

## 3. 高阶保命机制

元婴境后可解锁：

- 元婴遁逃
- 神魂保命符
- 宗门赎回
- 残魂回归

这些可以减少高阶死亡损失。

# 十七、玩家完整流程示例

## 1. 进入前

玩家当前是炼气五层。

准备进入"废弃灵田"。

**携带：**

- 长剑，占 4 格
- 匕首，占 2 格
- 劣品灵石 5 个
- 火属性石 3 个
- 水属性石 2 个
- 回灵丹 1 瓶
- 背包剩余 10 格，用于搜刮

## 2. 局内前期

玩家遇到低级妖兽。

选择普通攻击，不消耗属性石和耐久。

**获得：**

- 低阶灵草
- 1级木属性石

## 3. 局内中期

玩家发现精英怪守着宝箱。

**判断：**

- 普攻太慢
- 灵力还有一半
- 武器耐久 42/50
- 有 1 颗火属性精纯石

玩家使用火属性石附魔。

**结果：**

- 本次攻击增加火伤
- 触发灼烧
- 消耗武器 5 点耐久
- 消耗 1 颗火属性石

击败精英怪后获得：

- 青玉灵果
- 筑基丹辅材
- 2 颗灵石

## 4. 局内后期

玩家背包接近满，武器耐久只剩 17。

此时发现更深处有高级资源点。

**玩家需要选择：**

- 继续深入，可能获得高价值资源，但武器快坏
- 直接撤离，保住已有收益
- 吞服青玉灵果，提升修为，继续冒险
- 丢弃低价值材料，腾空间

最终玩家选择撤离。

## 5. 撤离后

**玩家获得：**

- 青玉灵果
- 低阶灵草
- 灵石
- 木属性石
- 筑基丹辅材

**后续选择：**

- 青玉灵果直接吃：+80 修为，+5 丹毒
- 炼成青玉培元丹：+140 修为，+1 丹毒

玩家选择炼丹，准备冲击炼气六层。

# 十八、项目亮点总结

## 1. 末法修仙设定有差异化

玩家不能挂机修炼，必须冒险争夺资源。

## 2. 搜打撤和修仙天然融合

秘境、机缘、杀怪夺宝、撤离、炼化，都符合修仙题材。

## 3. 战斗是资源消耗决策

每次附魔都消耗属性石和武器耐久，不是无脑输出。

## 4. 背包空间形成真实取舍

多带战斗资源就少带战利品，多留空间就降低战斗安全感。

## 5. 直接吞服和炼丹形成长期选择

短期救命和长期收益之间存在明显取舍。

## 6. 境界不只是等级

境界决定秘境准入、战斗机制、撤离能力和成长路线。

# 二十、最终项目定义

这款游戏可以定义为：

> 一款末法时代背景下的 2D 修仙搜打撤游戏。玩家无法通过普通修炼提升境界，只能进入秘境争夺天材地宝，以灵石维持战斗灵力，通过有限背包管理武器、属性石和补给，在高风险探索中完成搜刮与撤离，并将带出的资源转化为修为、丹药和突破资粮。战斗围绕武器耐久与五行附魔展开，每一次出手都是资源消耗与收益判断。
