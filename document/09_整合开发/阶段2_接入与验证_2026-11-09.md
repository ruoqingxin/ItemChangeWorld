## 1. 可玩入口与范围

预览：`http://127.0.0.1:18120`。Lobby 与预览默认均进入剑土双道试炼；原剑道单场以开发预览参数 `?stage=1` 保留回归入口，游戏内不提供新旧规则切换。

入口未建档时可选择默认新手或明确标注的学书隔离夹具。入境立即保存起点/二十分钟截止与起始三个候选；必须取一个后才能战斗。默认候选仅来自点星刺、裂甲斩、飞岩术、岩甲诀，不赠书、不装配整套被动。只有剑土一个合法组合，不显示/调用重抽广告。

有限六场顺序引用既有普通、持盾、普通、精英、普通、持盾夹具；第 1/3/5 战后各一次主动机会，第 2 战后开放一次独立悟道。它们是明确的流程/奖励来源 ID，不是 R07 正式节点图或 R08 掉落。战斗失败、超时或完成演练会清本局构筑，不结算愿力或真实物品。

默认入口实测覆盖前两场、放弃换点、强化、资源携带与悟道；六场完整状态机和部分极限替换分支使用明确的低血/零伤敌人隔离夹具验证，不能据此宣称默认六场通关平衡通过。

## 2. 实际实现

| 对象 | 改动 |
| --- | --- |
| `NewBattleTypes/Core` | 扩展五土道主动、六土道/四通用被动、磐劲/首次标记、有限减伤与反击；条件倍率 BigInt 完整乘算后一次舍入 |
| `NewBuildConfigUtils` | 从实际生成的三张新表与原剑道表读取内容、默认资格、奖励参数；显式隔离学书夹具 |
| `NewBuildTypes/Rules` | 保存随机状态的确定性构筑归约器，候选无放回、起始必选、三槽、强化替换、道韵/悟道、来源唯一与结束清理 |
| `NewBuildSession` | 独立存档、完整命令重放、配置签名比较、修订令牌、旧页原文比较、写前截止与失败不半扣 |
| `NewBuildPanel` | 复用现有 Start prefab 做起始/候选/战外构筑；复用 NewBattlePanel 战斗；强化下一档、替换同档比较/取消、被动与历史 |
| `UISession/Views/Navigation/Lobby` | 共享工厂默认接新构筑流程，保留原 UIManager/UIBaseView/ElementMapper、1280×720 横屏与原资源 UUID |

新核中磐劲只放大直接本体；减伤先于抵盾；死亡先截断；存活吸盾后才登记下一次磐劲/处理返震。药引盾、固脉标记和首次记录与独立用药一起提交，不推进主行动或打断递锋。新增被动不递归，反击不能兑现锋意/磐劲或触发攻击被动。

构筑每次生成候选即保存。途中有候选可取主动或放弃换两点，三主动全 +5 的已定例外不给无用途点。替换只继承次数，原技能仍可回后续合法池，不退款/不保留备用。道韵多阈值逐个选完再更新池；最多混一个通用，大道收齐后单通用，全部合法内容收齐停累计。

未删除尚有引用的旧探索模块，不把文件删除当迁移完成。默认链不实例化旧 ExpeditionManager/旧存档适配器，不调用旧公式、注灵或守势反击。

## 4. 存档契约

新键 `nowchange.stage2-build.v1`，结构版本 1。原 `nowchange.stage1-battle.v1`、现行 v2 和其他应用键不迁移、不删除、不覆盖，本轮没有执行旧档清理。

保存配置/资格夹具快照、种子、起点/绝对截止、带时间戳的完整命令，以及包含随机状态、候选、构筑、奖励来源、每场 setup/initial/actions/state 的最终快照。每次写入/恢复从起始同规则重放，比较整个最终快照；每场独立锁定当时构筑，后续强化不回写历史。

Session/Manager 先比对动作结果再写，保存成功才发布新状态；重复/过期战斗或构筑修订拒绝。关联敌人死亡、奖励道韵、来源已结算与候选生成同一提交，不存在先胜利后补奖的半写。独立已保存药品不因之后失败/超时撤回。

写入前比较原始文本并在最后一次写前核截止；失效旧页不能覆盖新修订。默认入口当前配置签名改变时保留原档并阻止静默兼容。损坏档同样保留，仅显式二次确认后删除自身键。

本地 localStorage 不提供可靠的跨进程原子比较交换或可信时钟；本轮不承诺跨端、强多窗口锁或防篡改。终局清本局构筑，但保存历史战斗以供报告，不把历史快照重新装配到新局。
