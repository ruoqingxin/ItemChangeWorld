# 局外经济学习与成长

## 1. 资源分工

首版愿力是唯一交易货币，统一商店、常备补给、出售、建筑维修。技能点、道韵、修为各自独立，不合并互兑；新版不维护灵石交易余额。

出售对应实际物品是愿力主要来源，出售后物品扣除，不自动出售所有带回物。旧灵石物品、旧余额保留，不自动改名、兑换、合并或迁移。

## 2. 一个商店入口，两类货源

| 货源 | 范围 | 资格与库存 |
| --- | --- | --- |
| 今日货架 | 回血药、回蓝药、低档纳虚器、武器 | 不要求先带出同款；每日有限库存，不手动/广告补货，退出不刷新 |
| 常备补给 | 首版仅基础血药、基础蓝药、最低档纳虚器 | 入门直接开放这三项资格，解锁后逐份付愿力，不设每日限购 |

其他非初始化补给资格仍须首次成功带出，不能把买到、发现或学书等同于带出。当前首版名单不能据此扩成所有物品可无限补给。今日货架与常备重叠商品可有价差，一次采购只走一个渠道，不重复扣库存/愿力或生成两份。

刷新时区、时刻、日期边界、轮换、数量和价格仍待经济表。旧推荐“04:00 Asia/Shanghai”未获正式确认。刷新不删除已购物品，普通库存不自然到期。

## 3. 初始化与防套利

首次一次性赠最低档纳虚器、少量血药蓝药和愿力，具体数量待完整成本表；不每局重发、不自动加送武器。三项常备资格和实际赠送数量分开记录。

统一价格矩阵要求同物回收价低于所有可重复购入渠道的最低价，连同品质、耐久与维修成本检查，不靠跨日倒卖刷愿力。具体比例未定。

已有物品携入不收入境锁定费、不重复收生成费、无转换费。实际购买新份数和主动维修仍付相应费用。无武器、无纳虚器仍可入境，不把失败变成购买门票。

成长丹药、珍稀灵材靠探索与层级产出，不凭图鉴或愿力无限生成，不自动进每日货架。首版不做玩家交易。

## 4. 技能书与资格

实际带回对应书 → 玩家消耗一本学习 → 永久记录对应技能/术式版本资格 → 满足境界及本局两道等条件后进入候选池。

- 带回不自动学习，局内拾取与临时借到不等于永久解锁。
- 归真匣在失败时保住并实际带回的书也能学习；掉落丢失的书不能学习。
- 高阶书可提前消耗收录，但不到境界不能借用，不能越阶施放。
- 重复书保留出售，不做共鸣、碎片合成或重复书强化，不自动转技能点。
- 掉书按忆境主题，不完全绑定本局两道；可掉未来道的书，但不开放本局第三道技能。首领不保证指定书。
- 一本书只解锁对应技能或术式版本，不卖整道许可证，不因一本书开放整条道。
- 永久术式进阶首次同样消耗一本对应进阶书，不另扣愿力、修为或局内点，后续不重复交书。
- 同术式用当前已解锁且境界合格版本，不做主动降级、自由切换或多版本并装；独立低阶技能仍可借，进阶不能损害原定位。

图鉴发现、首次带出/补给资格、消耗书学习是三个不同记录，不能彼此替代。首次发现可标记“未带出”。

## 5. 修为、境界与本源

永久修为在局外消耗实际带回成长资源推进，不以击杀经验或局内道韵直接增加。首版先炼气小阶段；精确层数、消耗、突破材料、属性收益仍须表，不把旧炼气九层到筑基清单或推荐前三层数值直接定稿。

本源跟随关键忆境/剧情节点一次性推进，重复探索可拿物资但不反复领同份永久奖励。第一批优先功能与容错，避免开局全属性暴涨；扩安全空间、信息辨识、有限应急仅是方向，具体能力、次数、节点、上限及失败是否可触发逐项确认。

清浊道是本源专题，不进普通随机池，不自由复制全部至强技能。旧图保留补给收藏价值，不默认动态追平玩家，也不从低阶图无限产高阶收益。目标境界、压制公式与掉落层级另表。

唯一信物、本源遗蜕不无限生成、不普通售卖，占格保护逐件定。首图线索与遗藏需对照小说源稿，不提前泄露终局。
