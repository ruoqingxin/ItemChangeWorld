## 2. 沿用项目分层

LayaAir 3.x + TypeScript，`src/script/module/<feature>` 组织业务；数据层用 `*Data.ts`，不新造 `*Model.ts` 习惯。沿用 `ModuleManager`、`BaseModule`、`UIBaseView`、`UIManager`、`EFuncID`、`EventEngine/Events` 等现有设施。

| 层 | 职责 |
| --- | --- |
| Module | UI、协议、红点、入口注册与登录/跨天生命周期 |
| Data | 运行时数据与已提交状态 |
| Manager | 跨界面流程、业务编排与事务入口 |
| View/Panel | prefab 绑定、交互与呈现，不另写战斗公式 |
| Ctrl | 子控件和列表项 |
| Utils | 纯规则、配置读取和辅助计算 |
| ProtoUtils | 已有网络场景的发包封装，不为本地首版额外造联网需求 |
| types/enum | 清晰的数据契约和枚举 |

当前相关模块为 `module/skillBattle`、`module/expedition`；新版战斗核文件在 `module/skillBattle/newRules/NewBattleCore.ts`。开工先核对现有职责、调用链和用户改动，不以旧树形提案重建整个工程。
