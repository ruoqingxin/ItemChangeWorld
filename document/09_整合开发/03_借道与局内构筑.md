# 借道与局内构筑

## 1. 借道与道性

局外先准备实际物资，入境后从当前开放名单随机两条不同大道。清浊道不进普通随机池，通用被动也不是第三条道。先剑道、土道验证，阵道在闭环后加入；土道及首批通用内容已于 2026-11-09 获准作为可调整测试起点。

阶段 2 的批准轨迹、逐档算例和合法新手池证明见 [双道与构筑确认包](阶段2_双道与构筑确认包.md)，实际范围见 [接入记录](阶段2_接入与验证_2026-11-09.md)。新增内容不改变既有抽取、资格、奖励或保存规则。

合法两道组合等概率；主动从合并后的合法池等概率无放回抽取，不加主辅权重、稀有度或隐藏保底，不要求每道各占一个。道性借到该道后自动生效、持续本局，不是额外领取的被动，也不占主动位。

## 2. 起始广告与恢复

- 一局最多一次观看广告后的两道整组重抽，不能保留单道；存在其他合法组合时不重复旧组合，成功后不能退回。
- 先定两道，再生成起始主动候选。只有两道、没有其他合法组合时不播放无意义广告，不改成免费刷新。
- 广告失败、取消、无填充不扣机会、不改当前两道、不强制退出；未超时仍可接受原组合。
- 广告完成但保存失败需防重复扣机会，重复回调不能重复重抽。播放和异常等待照常计时，超时先失败。
- 恢复同局保留两道、已确定候选、随机状态与已用重抽次数。成功/失败结束并结算后，新局才能重新抽取；是否打过战斗不是结算前提。
- 不新增主动候选刷新、锁定、指定保留或第三道体验广告/节点。

## 3. 候选资格

主动资格是本局两道、境界合格、默认或永久已学资格、当前未装配同名的交集。被动使用获准两道/通用来源与境界、解锁资格，并排除本局已得同名。单次候选也去重，同术式不同版本不重复占位。

被替换离场的主动可重新进入后续合法池；永久学习记录不删除。不开放任意禁用已学技能来缩池。缺少药品或配套主动等软条件不一律过滤，可为后续构筑布局并说明触发；完全不满足的硬资格排除。

同术式采用当前已解锁且境界合格的版本，独立低阶技能仍可出现；不因替换、强化或继承绕过境界和书籍资格。

## 4. 起始主动

展示三个不同且合资格主动，必须取一个；不能放弃换点，不额外送技能点或被动。通过开放名单与默认资格保障任意合法双道组合的新手起始池足够，不用未解锁、重复项或第三道凑数。

默认可借不等于自动取得；没完成起始选择不能正常开始战斗。起始选择占二十分钟探索时间。

## 5. 途中主动与替换

| 场景 | 处理 |
| --- | --- |
| 途中正常奖励 | 取一个主动，或放弃整次奖励换两个本局技能点，不能兼得 |
| 未满三个主动位 | 默认新增基础技能，也允许指定替换旧技能继承强化次数 |
| 已满三个 | 必须指定旧技能替换，始终最多三个 |
| 候选只剩两个/一个 | 展示两个/一个，仍可正常放弃换两点 |
| 无候选 | 正常直接给两点，不弹空面板，不塞重复或不合资格内容 |
| 三个主动均 +5 | 有候选仍可替换继承；放弃不再给无用途点数 |
| 三主动均 +5 且无候选 | 提前标明无可借内容，不空选、不补偿、不发点 |

先选新技能，再指定替换对象，同屏比较新旧档位与效果。确认前可返回原候选重选，但不刷新。只继承强化次数，新技能按自身档位结算；不保留旧专属效果、不同时退款、不加次数、不保留随时切回的备用栏。每次奖励只能领取一次。

“不发无用途点”仅按三个主动全满的已定例外处理；不自行扩大成单主动满级就停止所有换点。

## 6. 技能点与强化

每个主动初次获得是基础状态，此后可强化五次，共六种强度。正式显示“基础、+1 至 +5”，每次一点，升满五点；逐档保留此前收益。

技能点可本局暂存，战外随时强化，不必回借法台；战斗中不可强化。只对主动有效。成功/失败离境清空，不兑换愿力、物品或永久收益。

最低三次途中机会下的预算示例：取得两次新主动再换点可得三主动加两点；取得一次新主动可得两主动加四点；全部换点可得一主动加六点。这是选择预算，不承诺候选必出或每局全技能满级。

## 7. 被动与道韵

- 被动装配数量不限、无等级、不可强化、不可放弃换点；同次和本局已得同名去重。
- 尚有大道被动时，以 25% **测试概率**决定是否混入一个合法通用，每次最多一个；不足三项也不拿多个通用凑满。
- 剩二选二、剩一确认领取。两道合法被动已收齐、仍有合法通用时，每次随机给一个通用确认领取，不再掷混入概率。
- 两道及合法通用全部收齐才显示已悟尽，停止道韵累计，不再弹选择，余量不兑换；悟道建筑无替代奖励，正常战利品不受影响。

首图普通胜利 10、精英胜利 20 道韵；首次选择耗 30，此后每次耗 40，余量保留，不继续涨价。首领道韵未定，不能沿用建议 30 或推荐 JSON 的 40。

同次结算跨多个阈值时，战外逐个选完，再按更新后的已得名单生成下一组，不预先同时生成多组。中途池收齐就执行收齐逻辑，不产空奖励。

中段可选支路一处悟道建筑，独立多给一次被动选择，同局只领一次，不改道韵余额、首次阈值或后续阈值。所有候选一旦确定即保存，回退、关闭和恢复不刷新。

## 8. 收尾

正常战后先处理已触发的强制被动选择，再继续地图或正常撤离；选择仍计时，超时/失败不补偿未完成构筑。

成功和失败都清除两道、主动被动、局内强化、技能点、道韵，保留永久学习、境界、本源。同局未结束恢复不清除，也不刷新奖励。

## 9. 获准土道与通用测试内容
