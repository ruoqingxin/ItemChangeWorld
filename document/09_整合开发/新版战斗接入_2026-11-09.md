# 新版战斗接入

日期：2026-11-09。依据：用户明确“全部为我按推荐来，接入新版战斗核”。唯一入口仍是 [README](README.md)。

## 1. 批准与交付范围

[战斗确认包](阶段1_战斗确认包.md) 的 R01/R02/R03 推荐获准作为可调整测试起点，规则已归入 [02](02_战斗资源与结算规则.md)、[04](04_剑道内容与强化.md) 和基线测试区。R03-B 修补 +20 与战外边界获准，但投放、空间和价格仍后置。本次不批准土道草案、通用被动完整表、正式双道池、三空间、地图掉落或经济。

本轮交付阶段 1 的默认“剑道试炼”：真实 Laya UI、同一新版规则核、源表读取、可预览/确认/保存/恢复的一场战斗。可以显式选择三种敌人、五主动中的最多三个及各自基础至 +5、六被动、无/零耐久武器、无剑道与空匣夹具。学书主动/被动的夹具注入不写永久资格，不冒充正式借道或免费赠送。

胜利可继续同一条件试炼，保留实际 HP/MP/武器耐久/药品和原截止，只重置战内标记。每场历史快照独立保存，可在战斗记录翻阅。不是旧线性三战产品，也不是正式首图入口。

## 2. 当前调用链

```text
LobbyStage / preview-skill-battle
  → SkillBattleUISession.getTrial
  → SkillBattleStart/Battle/SettlementView (UIBaseView)
  → NewBattlePanel (现有 prefab / ElementMapper)
  → NewBattleSession
  → SkillBattleManager 新接口
  → NewBattleCore

ConfigUtil.Tables 六张新表 → NewBattleConfigUtils → 开战 setup
NewBattleSession 保存与恢复 → NewBattleCore 完整重放 → 对比 state
```

新核完整处理通用行动、独立药品、HP/MP、武器属性与跨零耐久、五主动/六被动、养锋/锋意/凝锋、两次阶段末剑痕、护盾和死亡截断。资源按百分之一整数与 BigInt 完整倍率计算，独立效果一次四舍五入，UI 最多两位小数。

预览不改正式状态；战斗/修订令牌、输入锁与写前旧文本检查共同阻止重复或过期提交。保存成功后才更新 Session/Manager 权威内存，之后播放已提交事件，动画不执行公式。伤害分本体/锋意/递锋/贯隙/剑痕展示；战内构筑只读。

沿用 1280×720 横屏、UIManager/UIBaseView 与三个 prefab UUID。复用原节点提供两通用按钮加三主动槽，不以技能 ID 作槽位；第三主动槽复用映射节点 `upgrade0`。保留真实背景 PNG，未创建 HTML 替身或第二套 UI 根。

## 3. 源表与生成

人工源表为配置工程 `Datas/N-新版战斗配置表.xlsx`，新增 rule/skill/passive/intent/enemy/potion 六页，在 `__tables__.xlsx` 注册。其余源表不改。使用相同 Luban 参数分段执行，校验退出码后运行现有 packall，再复制生成代码与包，不手改 schema 或 bin。

对照配置工程 HEAD 的原 23 个表块逐表字节一致，新增六表后共 29 表。旧客户端原包仅 item/skill 与源工程不同；本轮已读取相应源页确认旧四招与旧物品定义，客户端独有提案记录不回写源表。既有配置/旧逻辑 143 项回归在重新生成包上通过。

## 4. 存档

- 独立键 `nowchange.stage1-battle.v1`，版本 1；不迁移、不清理、不覆盖 `nowchange.skill-expedition.current.v2`。
- 保存起点/绝对截止、timeout 时间、每场开战配置/初始状态、带时间戳动作序列与状态；装配与技能档位随开战快照冻结。
- 药品独立增加 revision，不增加 round/mainActions，不推进意图/剑痕、不清盾。药后失败或超时不回退已提交消费。
- 恢复与每次保存都用同一核完整重放，快照、资源、跨战连续性或版本不符即保留原档并阻止继续。
- 写失败不发布候选结果；超时保存失败保留上一有效状态并重试。250ms 检查、focus/visibility 恢复与提交边界共用截止。
- 仅 UI 二次确认后清除试炼键，不执行 localStorage.clear。测试用浏览器独立上下文，不接触用户浏览器实际进度。
- 同步 localStorage 的文本比较能拒绝已观察到的较新版本，但不是跨进程强事务锁，不承诺可信系统时间、跨端同步或防篡改。
