## 3. 推荐 JSON 的适用性核查

原 [首版推荐配置数据](参考资料/原始快照/08_小说设定融合/首版推荐配置数据_2026-11-08.json) 已完整保留，但不可直接导表：

- `economy.spiritStoneEnabled: true`、`startingSpiritStone` 与最新单币冲突。
- 归真匣 `width: 2, height: 2` 为四格，与初始两格冲突；纳虚器 8×6 未定稿。
- `defaultWeaponId` 不构成正式首次赠送；若用于测试夹具，必须明确标注。
- 首领 `daoyun: 40` 未批准，旧建议 30 同样未批准。
- `attackSpeed` 不得使首版暗加速度系统；土道系数/道性、成长属性、刷新时刻、药品/维修量和初赠数量都未因文件存在自动获准。
- 点星刺 `damageRatio: 1.5` 是推荐基础值，不等于已接受的 +5 相对基础 150%，不能混用两个百分比含义。
- 书籍/其他材料堆叠、保护白名单、物品 ID 与正式 schema 仍须核对，不因其为 JSON 便成为工程合同。

可核对的已定参数已另列 [规则基线](数据/已确认规则基线.json)，测试参数与未知值分区，避免继续传播冲突推荐值。
