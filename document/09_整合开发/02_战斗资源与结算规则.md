# 战斗资源与结算规则

## 1. 战斗底座

- 固定站位、一对一、敌人当前意图可见。每个自身回合一次主行动，可选普攻、防御或已借主动，不自动普攻、不新增通用冷却或空过机制。
- 普攻、防御属于角色，不占三个借法主动位；武器只提供属性，不附送旧贯虹、破势。
- 无武器仍可基础战斗；低蓝、零耐久不能变成必须购买出战资格的门槛。
- 当前已展示意图不能在确认后临时重抽。具体敌人意图与机制以获准内容表为准，贯隙本身不打断。

## 2. 血蓝与物品

新探索按当前上限满血满蓝；同局跨战斗与恢复存档保留实际余量，不自动补满。普攻、防御不耗蓝，也不默认回蓝；战外等待不回蓝。首批不做持续自动回灵，后续恢复效果应有次数或构筑代价。

| 情况 | 现行规则 |
| --- | --- |
| 战斗药品时点 | 仅在本回合主行动确认前使用，用后仍有一次主行动 |
| 次数 | 每自身回合最多一次，回血与回蓝共用；主行动中、敌方阶段及出招后不能补药 |
| 战斗库存 | 仅斗法匣实际库存，不能跨空间补入或打开完整背包 |
| 战外用药 | 三空间内的实际药品均可使用，不受战斗每回合一次限制，仍计时 |
| 药品内容 | 首批纯血药、纯蓝药各一种，试炼恢复量为 HP 20 / MP 10，逐份占位不堆叠；是获准测试值 |
| 满状态 | 满血禁用纯血药、满蓝禁用纯蓝药，不扣物品或使用机会 |
| 溢出 | 不保留、不转盾、不留后续额度 |
| 未开放药品 | 首版不加血蓝双回、增益或复活药 |
| 其他物品 | 不占药品机会，不设所有物品共用每回合一次；各自条件、动作占用须逐项明确 |

用药不是主行动，不推进敌方意图、不清盾、不打断递锋衔接。独立成功提交的药品消费是已完成历史动作，不能因之后主行动超时而回滚。

## 3. 武器与耐久

- 每次合法主行动消耗武器耐久 1，不限于直接攻击，防御与凝锋也扣。无武器不扣，零耐久不扣成负数，用药/无效/取消不扣。跨 1→0 的整次行动锁定开始时完整属性，下次行动才取半武器贡献。这是 2026-11-09 获准测试口径。
- 所有武器可卸下放入合法背包空间，受占格和战斗禁背包约束；不由此开放战斗中换装。
- 零耐久只使武器提供的属性减半，不使角色总属性减半、不归零角色基础能力；非零耐久不默认按比例衰减。
- 新局、跨战斗、恢复和携入带出均不自动修满。局外建筑可用愿力修满，价格待表。局内基础修补获准测试值为每件 +20 耐久，仅战外对实际武器使用，满耐久/无武器禁用，不占主行动或药品机会，仍计时；投放与空间实现留阶段 3/4，不在单场夹具免费发放。
- 所有装备失败掉落，无铁剑身份例外，详见 [05](05_物品储物与终局结算.md)。

## 4. 护盾、伤害与死亡

玩家默认护盾同回合多来源可加，承受本次敌人行动及反击后清除，不跨战斗。更长护盾须技能明确获准。

敌方护盾用于抵挡下一次玩家主行动，不能在获得当回合立即清除；用药不构成玩家主行动。旧敌盾在玩家主行动后、敌方意图前到期，新敌盾可抵挡本次阶段末剑痕并保留到下次主行动。

先处理技能前置削盾，再处理本体与明确附伤。锋意、破盾、被动按对应事件触发，不相互递归。每次实际伤害后立即检查死亡并截断，不追加同归结算，不允许已死亡玩家靠之后反击或药品复活。

剑痕受正常护盾抵挡，同名刷新不叠层，与旧灼烧分开。已接受“两次敌方阶段结束、施放瞬间不跳伤”为测试方案；这不是把旧灼烧的敌方阶段开始跳伤、穿盾及层数规则搬给剑痕。首版不启用旧火石等注灵来源。

## 5. 强化与无效行动

局内强化只增强技能指定效果，不再次乘算锋意、被动或其他来源的盾；凝锋诀指定增强本轮锋意的规则单独保留。

完全无实际效果的施放禁止，说明原因，不扣蓝、不占行动；收益较低但仍有收益的选择允许。无效点击、查看与取消不冻结现实倒计时。

## 6. 预览与提交

预览与执行共用纯规则函数。预览只计算副本，不改正式状态、不扣资源、不消耗或重新抽取随机数。直接、本体附加与持续伤害分项展示，延迟伤害不能冒充立即击杀。

主行动先在临时状态完成整回合逻辑，扣蓝、耐久、物品消耗、敌我状态和结果成组保存，保存成功才算完成。药品可独立提交；若提供药品加行动组合入口，也须清楚定义原子边界，不能吞掉药后主行动机会或撤销已提交药品。

提交前检查真实截止时间，达到或超过即按上一有效状态失败结算，本次结果不提交。输入锁定、快照过期与重复提交均需校验；动画与存档规则见 [06](06_地图搜索撤离与计时.md) 和 [09](09_工程配置与存档约定.md)。

## 7. 获准测试底表

2026-11-09 用户明确“全部为我按推荐来，接入新版战斗核”，批准 [战斗确认包](阶段1_战斗确认包.md) 的 R01/R02/R03 推荐作为测试起点，不等于最终平衡值。运行配置真源是配置工程 `N-新版战斗配置表.xlsx`，不是文档 JSON。正式经济、掉落、土道与双道池仍未因此获准。

| 项目 | 测试值 |
| --- | --- |
| 角色 | HP 60、MP 30、基础攻击 B=10、基础防御 6 |
| 测试武器 | 攻击 +4、防御 +2、耐久上限 60，不授予技能 |
| 有效攻击 A / 防御 D | 角色基础 + 武器贡献 × r；非零 r=1、零 r=0.5、无武器贡献 0 |
| 普攻 / 通用防御 | 伤害 A / 本回合盾 1.5×D；防御不另设常驻减伤 |
| 锋意 | 0.5×B，独立于兑现主动本体强化 |
| 药品 | HP +20 / MP +10，上限截断；仅独立用药入口 |
| 资源精度 | 百分之一单位安全整数；单独效果完整倍率一次四舍五入至 0.01，不浮点逐段舍入 |
| 普通夹具 | HP 56，攻击 10→攻击 10→明确蓄力攻击 18 |
| 持盾夹具 | HP 60，盾 10→攻击 8→明确蓄力攻击 18 |
| 精英夹具 | HP 90，盾 14→攻击 14→明确蓄力攻击 24 |

夹具药匣两血药、两蓝药、一个空格，每份独立 UID；可显式选空匣。不是永久学习、正式开局赠送或掉落。

## 8. 获准事件顺序

| 顺序 | 事件与边界 |
| --- | --- |
| E00 | 校验战斗/修订令牌、阶段、截止、装配、蓝量及实际收益；失败不扣 |
| E01 | 锁定本次 A/D/B；扣 MP/耐久；兑现出剑先锁定并消费锋意与剑势 |
| E02 | 前置削盾，仅削实际盾；符合条件立即崩甲，每主行动合计一次 |
| E03 | 普攻/攻击主动本体，或通用防御本体盾；每次伤害立即死亡截断 |
| E04 | 存活才结算回澜本体盾 |
| E05 | 锋意附伤；存活才敛芒得盾、登记息锋；不递归 |
| E06 | 递锋、贯隙依次独立附伤，每次伤害检查死亡 |
| E07 | 普攻/防御养锋与初照/息锋合并；凝锋实际增势并登记增强；留痕安装/刷新剑痕；记录主行动身份 |
| E08 | 清旧敌盾，不清随后新盾 |
| E09 | 执行已公开意图，新获敌盾保留；贯隙不打断 |
| E10 | 玩家死亡先失败；阶段 1 无获准反击来源，不继承旧守势反击 |
| E11 | 双方存活才剑痕一次，正常抵盾并扣次数；致死不再生成下一意图 |
| E12 | 清玩家本回合盾；双方存活才推进回合/意图、重置用药机会 |
| E13 | 再核截止，原子保存全部资源、状态、行动与结果；成功才发布和播放事件 |

崩甲仅响应合法攻击主动的前置削盾、本体或锋意实际破盾，最多一次；递锋/贯隙、剑痕、盾到期不触发。留痕施放瞬间不跳，第一次在本次敌方阶段结束；同名刷新为新伤害与两次，不叠层。致死仍保留本次 MP/耐久费用，结束清战内标记。

独立药品只恢复实际缺口、消费实例、登记本回合已用并增加修订，不推进主行动/回合/意图/剑痕，不清盾或断递锋；保存成功后旧预览令牌失效，写失败不消费。之后主行动失败、取消或超时不能回退已保存药品。

来源：08 主规则第 13-14、20-22、25、29 节，C/J/P/B 组结论；07 底座中未被新版更改的意图、预览与护盾原则。
