## 1. 行动与代价

每个存活单位每回合一次主动行动。开场按速度确定固定顺序，同速时玩家先手。没有额外主动行动或概率追击。

本轮新增“战术转化”：在自身主动行动前，可以选择一次已学会的纯状态转化；所有战术转化共享这一机会。必须支付法力、消耗目标当前已有的层数，且目标存活。更快的敌人先行动，不能在它攻击前抢用本次转化。

战术转化不造成伤害、不积累藏锋、不切换换脉、不产生四种共享状态。转化后再选择本次主动技能；因此可以先消耗旧状态，再用主动技能补回，但不能在补回后再转化一次。转化本身仍占学习预算。

| 能力类型 | 主要收益 | 必须承担的代价 |
| --- | --- | --- |
| 低耗物理 | 稳定攻击、续战 | 通常较低的即时伤害，或需要状态/破甲铺垫 |
| 魔法爆发 | 较高的即时或群体伤害 | 法力消耗、状态消耗或布置等待 |
| 持续状态 | 多回合收益、为其他技能提供材料 | 等待结算，可能被净化，目标提前死亡会损失收益 |
| 战术转化 | 保住主动行动，临时改换用途 | 消耗原状态及其未来收益，每回合全体共享一次机会 |
| 防御与恢复 | 保存生命、寻找下一次攻击窗口 | 占主动行动，消耗法力，并可能丢失击杀时机 |
| 燃血与化灵 | 较弱攻击同时准备增幅或回复法力 | 支付真实生命、占主动行动；不能用护盾或减伤抵扣，攻击倍率低于普通伤害技能 |
| 护盾转伤 | 将已有防守资源兑现为攻击 | 实际扣除护盾，之后更容易受伤 |

冷却N表示使用后跳过接下来的N次自身行动，之后才可再次使用；冷却0表示下一次自身行动即可使用。战术转化同样按自身行动次数冷却。

## 2. 统一结算

记A为物理攻击，S为精神力，H为生命上限，M为法力上限，R为护甲。

- 物理、魔法分别基于A、S计算；混合技能逐段结算。两类伤害都按`原伤害 × 100 / (100 + 护甲)`减伤，再扣护盾，再扣生命。魔法没有天然穿甲。
- 正伤害减伤后四舍五入且最低1。持续伤害逐层结算；这会产生小数值取整效应，属于后续仍需观察的实验条件。
- 基础治疗采用`10%H + 50%S`，基础护盾采用`12%H + R`。精神力不直接提高铁衣护盾；精神力对回春只提供部分收益。
- 玩家总护盾不超过30%H。护盾不自然消散，但战斗结束清除；护甲不产生护盾。
- 所有直接伤害增幅相加；反击、伏雷、持续伤害和被动附加伤害不能递归触发被动或吸血。
- 吸血只按原技能实际扣除的生命计算，排除护盾、过量伤害、反击、持续伤害和存锋追加。主动耗血不计受击。
- 燃血、血契、化灵统一支付`max(4, ceil(当前生命×4%))`生命；生命必须严格大于支付量。按付款时的生命计算，无低血免死保护。血契额外耗蓝；化灵回复仍受法力上限约束。
- 普攻造成实际生命伤害时回2点法力，击杀也可恢复。打在护盾上不回蓝；不额外给其他技能普遍回蓝。
- 最后一名敌人死亡立即结束战斗。生命、法力可跨战保留；状态、护盾、冷却与其他临时积累清除。

## 3. 四种共享状态的出口

| 状态 | 保留时的作用 | 攻击用途 | 防御/恢复用途 | 转化后放弃什么 |
| --- | --- | --- | --- | --- |
| 流血 | 每层每轮10%A物理伤害；至少3层时，目标治疗降低30% | 截脉消费2层，攻击并压低下次攻击伤害 | 血偿消费最多2层，每层恢复30%A生命 | 剩余持续伤害，可能失去三层禁疗门槛 |
| 灼烧 | 每层每轮15%S魔法伤害 | 焚尽提前结算；借焰斩保留层数获得额外伤害；焚风复制传播 | 灰烬衣将剩余伤害的一部分转盾；火息消费层数回蓝 | 同一批火不能同时保留、引爆、换盾或回蓝 |
| 寒意 | 每层使目标直接伤害降低6% | 碎寒击消费层数追加魔法伤害 | 回霜消费层数治疗并净化；霜封消费2层压制下一次攻击 | 原有的持续减伤，并可能影响后续碎寒爆发 |
| 雷印 | 储存可用于后续技能的材料，本身无伤害 | 惊雷单体爆发、雷链群体增伤、雷贯物理段穿甲 | 雷回流回蓝；霆护按生命上限生成盾 | 每份雷印只能走一个出口，提前换盾就减少后续爆发 |

流血、灼烧最多5层；寒意、雷印最多3层。四种状态均持续3个轮末，施加当轮计第一次，不刷新旧层时间。流血/灼烧记录施加时的A/S，传播保留原威力和剩余次数。

消费时优先取剩余时间短的层，时间相同优先取威力低的层。层数满时不覆盖旧层。寒意只降低直接伤害，不追溯降低已经生成的持续状态。

截脉、霜封的压制只作用于下一次直接攻击，最多保留至下回合末，同类取最高值，触发后清除。与寒意按乘法结算，不把普通攻击变成跳过行动。

## 5. 七项战术转化

所有项目共享“每次自身行动前一次”的机会。它们不能继续触发第二次转化。

| 技能 | 耗蓝/冷却 | 材料与收益 | 明确损失 |
| --- | --- | --- | --- |
| 血偿 | 2/2 | 消费目标最多2层流血，每层恢复30%A生命 | 失去对应剩余伤害，可能跌破禁疗门槛 |
| 灰烬衣 | 2/1 | 消费最多2层灼烧，将它们剩余原始伤害的60%转盾，最多15%H | 转成护盾的伤害不再灼烧或引爆 |
| 火息 | 0/2 | 消费最多2层灼烧，每层恢复2点法力 | 以火的未来伤害换资源，仍可能被冷却限制 |
| 回霜 | 2/2 | 消费最多2层寒意，每层恢复4%H，并清除自身一种负面状态 | 目标重新获得部分输出能力，碎寒材料减少 |
| 霜封 | 2/1 | 消费2层寒意，目标下一次直接攻击降低45% | 放弃两层持续减伤，换取一次更强的压制 |
| 雷回流 | 0/2 | 消费最多2层雷印，每层恢复2点法力 | 不能再用这些印爆发或穿甲 |
| 霆护 | 2/1 | 消费最多2层雷印，每层获得6%H护盾 | 火力储备改作防守，护盾不增加雷印 |

七项均以一个存活敌人为材料目标。本轮尚未模拟给友军治疗或护盾。

## 6. 六项被动

| 被动 | 本轮规则 | 边界 |
| --- | --- | --- |
| 藏锋 | 每次非伤害主动行动积累1层，最多2层；下次直接伤害每层加15%，随后清空 | 战术转化不积累；伏雷属于布置，之后的爆炸不消费或触发藏锋 |
| 识隙 | 直接物理伤害命中已被破甲的存活主目标，加1层流血 | 每招最多一次，持续伤害与追加伤害不触发 |
| 余烬 | 焚尽消费至少3层火，且目标存活时，结算后补1层火 | 新的一层不能回头参加当前引爆 |
| 守势化锋 | 护盾实际吸收的直接伤害40%存锋，存量最多80%A；下一次直接伤害释放后清空 | 主动扣盾不积累；释放伤害不再触发其他被动，混合技能的存锋按物理处理 |
| 血饲 | 吸血的溢出恢复转盾，来自血饲的存量最多10%H | 仍受30%H总护盾上限；真实吸收或消费后才释放额度 |
| 换脉 | 纯物理后使用纯魔法，魔法伤害加15%；纯魔法后使用纯物理，耗蓝少2且最低0 | 辅助行动保留记录；混合技能清空记录，不能一招同时获得两种奖励 |

被动的实验定位是改变操作与资源使用方式。装备如何投放这些效果、是否与装备被动重合，本轮未确定，也未加入装备贡献。

燃血、化灵现在是纯物理技能，会参与换脉与消耗既有直接伤害增幅，不能积累藏锋；燃血新获得的两次增幅从后续技能开始计算。血契仍是纯魔法，因此物理准备、魔法输出、物理吸血可以形成轮换，但每次付血都要纳入生存成本。

## 7. 六套比较组合

每套生命260、法力48、护甲12、速度10。攻击+精神力均为44。七项能力和两项被动只是相同学习预算；存在战术转化的组合，完整一回合可能同时使用一次转化和一次主动技能。

| 组合 | 攻击/精神 | 七项能力 | 被动 |
| --- | --- | --- | --- |
| 放血续战 | 32/12 | 断甲刺、裂帛、血偿、截脉、斩命、横扫、回春 | 识隙、藏锋 |
| 养火收火 | 12/32 | 点烬、借焰斩、焚尽、焚风、灰烬衣、火息、回春 | 余烬、藏锋 |
| 寒意转化 | 22/22 | 凝霜、碎寒击、回霜、霜封、断甲刺、横扫、回春 | 换脉、藏锋 |
| 雷印调度 | 14/30 | 雷引、惊雷、伏雷、雷回流、霆护、雷链、回春 | 藏锋、守势化锋 |
| 守势转攻 | 28/16 | 铁衣、守反、碎壁轰、饮血刃、断甲刺、横扫、回春 | 藏锋、守势化锋 |
| 血蓝轮换 | 24/20 | 燃血、血契、饮血刃、化灵、横扫、裂帛、涤尘 | 血饲、换脉 |

另做所有组合均为攻击22/精神22的对照，避免只看专精面板得出技能强弱结论。生命、法力、护甲和速度不随组合变化。

第二轮另做四个单项替换：放血组合的裂帛换回旋刃，守势组合的断甲刺换破障槌，雷印组合的惊雷换雷贯，养火组合的火息换化灵。每次仍为七项能力、两项被动，原组合与替换组合使用相同敌人和种子；专精与22/22面板各比较，不能把更多能力当成增强。养火另做双方都仅剩8法力的配对，检查换血回蓝是否真能补上资源短板。

## 9. 自动决策与局限

统一使用两回合、宽度四的前瞻，比较生命、法力、护盾、敌方剩余生命、状态未来收益及蓄势。持续伤害估值有折扣，避免把敌人即将净化或死亡后的伤害全部当作实际收益；燃血剩余两次增幅也按当前40%增幅计入估值。策略结构与其他估值权重不变。

测试包含12个种子、相同面板对照、专精面板、敌方生命和伤害同时上下15%、偏保命决策、初始8法力、去除新增转化的消融，以及两种连战资源预算。

自动决策不是最优解。更保守不一定更容易获胜，短视决策可能错误消费状态；技能被选择并不等于真人觉得有趣。技能通路也不要求每个场景都使用。三十四项能力有逐项合法执行检查；第二轮的单项替换让破障槌、回旋刃、雷贯也进入完整对局，但不代表已搜索所有搭配或证明最优平衡。
