# 青冥剑典第二轮优化与复测

日期：2026-11-16  
依据：用户明确“可以，帮我按建议再优化一轮”。  
状态：已更新独立功法测试原型并复测；本轮数值仍为测试起点，不是正式功法平衡定稿。

## 1. 范围与方向

保持四招固定成套、0星0阶至5星6阶、双方三行动、每操作一点行动、用药不耗行动。所有优化仅在独立`manualTest`模块内，不修改正式探索战斗、书本获取、碎片消耗、配置源表或存档。

主要目标：

- 第一把身剑立即有回报，三把身剑是深化，不再是体验的起点。
- 让逆引和身剑爆发使用同一份资源，形成取舍。
- 终式从正常轮转中自然取得，不要求为了资格长时间只普攻。
- 提供可操作的敌行动时机，改善成阵与截招的衔接。
- 补充低星调序、留锋、摹影、成熟收剑的局部回报，不通过全面抬伤害宣称解决所有问题。

## 2. 当前改动

### 一、二星：安排剑序与收剑更有回报

| 阶位 | 第二轮变化 |
| --- | --- |
| 1星3阶 调序 | 每己回合首次实际换首立即余响；原地选择原剑首不奖励 |
| 1星4阶 蓄势 | 成熟影主动落剑额外倍率由10提升至30个百分点，挤落不享受 |
| 1星5阶 引落 | 收取含成熟影的剑组时，本次技能续留一道引影；普通引落仍不留影 |
| 2星1阶 留锋 | 每己回合首次保留本命时额外加一势 |
| 2星3阶 摹影 | 除类型外，沿用队尾所选影至多两势；不复制身份、轮转 |
| 2星5阶 易位/拆阵 | 可使用与调序共享的本回合首次移剑余响 |

移剑余响仍与三才附加余响共享一次主动的额度，冲突时整次操作原子拒绝，不能叠加免费触发。

### 三星：可预约要处理哪一段敌行动

- 伏剑、点破均可指定敌第1/2/3行动。未指定时为第1行动。
- 预约组在更早行动不会被自动应剑或截锋提前用掉。点破支付并选定合法组后，即使回合末成熟，仍保留本次预约资格。
- 伏剑仅在预约行动为攻击时触发；玩家若约在敌蓄力/架盾处，不会自动改到后续攻击。
- 3星6阶后，一次剑阵回应计两次截招进度，散影仍计一次。达到两次进度后削弱下一敌行动25%，并非额外回应两次。
- 回应次数、每组限一次和首次回应回元均不翻倍。点破削弱和截招仍取较高值。

因此一阵也能形成截招，但它若在第一行动后回应，削弱的是第二行动；保留它到第二行动再回应，才能瞄准第三行动。散影与阵型仍有取舍。

### 四星：入体立即生效，出体成为蓄元爆发

纳剑门槛从三势降为两势；五星6阶保留“三转影也可纳入”。

| 类型 | 入体立即效果 | 持续作用 |
| --- | --- | --- |
| 锋 | 60%攻击的开锋伤害，吃当前剑痕 | 每回合首次本体攻击追加35%攻击，原20% |
| 守 | 一份基础护体H | 下回合开始50%H，原30%H |
| 引 | 立即叠2痕 | 每把引身剑提供2痕保底，仍受当前上限；保留首次引星额外叠痕 |

4星3阶出鞘的锋/守系数由30%提升至45%。4星4阶后，纳剑与实际坠落分别回一元，共享每己回合最多两元；4星6阶敌回合首次回应再回一元。

出体至少需要三元，消耗全部剑元。伤害为`65%A × 参与身剑数 + 40%A × 消耗剑元`，再乘剑痕等合法增益。三剑九元基础555%A，不是没有剑元也能无限按的普通攻击。

### 五星：逆引竞争资源，终式沿循环积累

逆引保留原重演和回升效果，额外消耗四剑元，每己回合最多一次。出体与逆引因此有直接的共享资源取舍；没有额外增加行动消耗。

5星6阶新增归冥势：

- 每道真实剑影每己敌轮次首次回升积一势，上限十二。剑阵三影算三势。
- 与原同影当轮记转检查共用身份门槛；同一影当轮反复下落/招回不会刷势。
- 转数达到上限后，后续轮次的首次正常回升仍能积势。
- 归冥势与当前天上排列分开，因此正常换剑、纳剑或压缩成阵不会清掉已积进度。

万剑归冥条件改为：十二归冥势、天影和归影合计至少三道、每战一次。不再要求满六悬或所有天影三转。

终式先以200%A剑鸣，再按现有顺序共鸣天影与归影，每道重演额外加80个百分点，最后合法身剑合击。原天影/归影均原地保留，不额外回元、增转、回升；身剑合击不耗元，归冥势清零且施展后不再积累。

## 3. 界面与结算边界

- 原生时机菜单支持伏剑/点破/悬落选择敌第几行动；战场显示当前预约。
- 冥渊标题显示归冥势、终式是否可用/已施展；预览显示逆引或出体的剑元开销。
- 纳剑菜单只列出满足当前资格的真实剑影；属性输入字号局部调整，最大七位数字能完整显示。
- 修正本体/身剑追加/敌回合回应已经击杀后继续派生的问题，防止终局清空后再回元或扣出负剑元。
- 所有操作仍经同一纯规则预览与管理器提交，失败完整回滚。未增加自动养成、存档写入、正式补给或新敌模板。

## 4. 前后对照

沿用首轮场景、回合上限与六类策略偏好，新增技能资格与时机候选随当前规则更新。依然是启发式自动策略，不是固定动作逐条重放或穷举最优解。首轮结果保留在`bin/manual-gameplay`，本轮位于`bin/manual-gameplay-v2`。

### 三星及低星

三星6阶首回合三次基础青锋，第三次成阵的固定对照：

- 成阵伤害仍471，回应仍只有一次；但现在能产生截招，承伤由300降至280。
- 三散锋仍441伤害、265承伤，截招打在第三击；阵型没有在所有指标上无条件超过散影。
- 原生界面可实际把点破预约到第三行动。专项校验爆发轮末段330%攻击被点破削至231%，预约组未被前两段抢用。

低星调序、留锋、成熟引落和摹影已具备更明确的局部回报，并有规则专项覆盖。但本轮十回合伤害抽样中，1星2～5阶最高仍5080，连续青锋仍有竞争力。本轮不能宣称已经解决每一小阶的可感知变化；后续应继续补不同攻防场景中的主动选择，而不是只追求伤害榜每行递增。
