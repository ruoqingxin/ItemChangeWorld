## 2. 必测边界

| 组 | 场景与断言 |
| --- | --- |
| 战斗 | 无武器/零蓝仍能基础行动；零耐久只减武器属性；耐久跨零按获准表 |
| 药品 | 主行动前血蓝共用一次；满状态不扣药/机会；药后仍可主行动；不推进敌方/清盾 |
| 剑道 | 零势可耗蓝施法；满三只生一锋意；正确技能兑现；凝锋待增强/满势无效；被动不递归 |
| 预览 | 副本无副作用、不重抽随机；本体/锋意/被动/剑痕分项与执行相符 |
| 候选 | 新手三候选；去重/资格/版本；未满可替换，满位必须替换；继承不退款/不留备用 |
| 奖励 | 起始不能换点；途中技能或两点只取一；不足/无候选/三主动满强；每来源只领一次 |
| 被动 | 通用最多一个；多阈值逐个生成；两道收齐转单通用；全收齐停止道韵且无补偿 |
| 物品 | 满格/旋转/禁入；不堆药；仓库与装备/容器/地面唯一归属；丢弃返取/结局清理 |
| 保护 | 所有装备失败掉落；安全空间只保合规非装备；保书带回仍须消耗学习 |
| 路径 | 直接入战无确认；已揭示但未通不可达；不越敌拿奖励/末撤离；合法另一支路可选 |
| 搜索 | 死亡掉箱时定物；逐件黑影；中断续搜；关闭/离线不自动搜；重开不复制已拾取物 |
| 恢复 | 每处免费一次；血蓝各 20%；双满不扣机会；单项满溢出；不修耐久、不读档刷新 |
| 撤离 | 无最低战数、不打首领可撤；末点必须过首领；首领后继续；全图完成不自动撤 |
| 计时 | 起始即计；整理/广告/动画/后台/离线不停；两个预警；无续时/复活/宽限 |
| 提交截止 | 点击前未到但提交到期无效；药已提交不撤回；普通动作动画超时失败；撤离提交成功后动画不改判 |
| 存档 | 写入失败不半写；重复行动/移物/奖励/终局不重复；恢复不重抽候选/箱/意图 |
| 广告 | 仅两道无替代不播；失败/取消/无填充不扣；重复回调、写入失败、播放超时；本地夹具不冒充正式平台 |
| 经济 | 初赠只一次且无自动武器；货架有限/重进不刷新；常备逐份扣愿力；跨日/失败/双击无套利 |
| 学习成长 | 实际消耗一本；高阶收录不越阶；发现/带出/已学区分；永久本源一次；临时构筑终局清零 |
| 界面 | 桌面/手机真实输入、长文本、网格操作、返回与弹窗不重叠，战内构筑只读 |

## 3. 节奏与趣味性验收

普通战约四至七回合是观察目标，不是硬性胜负条件。比较省物资、抢时间、按意图应对，以及一主动专精、两主动、三主动构筑，不能用一套固定最优策略证明有趣。

分别记录战斗、搜索、整理、借法、广告耗时与二十分钟内可走路线、撤离收益、失败成本。不能暗改二十分钟、完整探索八至十五战、选择暂停或新增最低撤离战数掩盖节奏问题。

首领应有风险，不是奖励机。自动测试全绿不替代人工试玩和趣味性反馈；正式平台广告、独立浏览器面板、完整工程分别说明验证范围。
