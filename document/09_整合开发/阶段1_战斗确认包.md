## 1. 本包解决什么

阶段 1 的目标是：使用同一个新版战斗核，在现有横屏战斗页完成一场可预览、可提交、可恢复的新版战斗，覆盖通用行动、血蓝药、武器属性/耐久和完整炼气剑道。

不同时开发正式双道候选、土道、道韵奖励、三空间、正式首图、商店或成长。阶段 1 的固定构筑、物资和敌人只作为验收夹具，不自动变成正式开局赠送、永久学习或地图掉落。

## 2. 不重新讨论的边界

以下直接沿用现行规则，完整定义见 02、03、04：

- 一对一、当前意图可见，一回合一次主行动；普攻/防御独立于最多三个借法主动位。
- 普攻/防御不耗蓝、不默认回蓝；无武器和零耐久仍能行动，技能不以剑势作通用施放门槛。
- 新探索满血满蓝；同局跨战保留余量。战斗药品在主行动前使用，血药/蓝药共用每回合一次机会，不占主行动。
- 只有本局借到剑道才启用养锋。每场零势、上限三；普攻/防御各加一，满势只生成一份锋意，剑道攻击主动兑现后清势。
- 凝锋基础增势二、+3 增势三，必须实际增势才登记本轮增强；满势不能白耗蓝施放。
- 五主动、六被动的名称、资格、职责和强化分工沿用 04；默认资格不等于自动取得。
- 既有强化倍率、剑痕两次敌方阶段结束结算是已接受的可调整测试起点，不是最终平衡值。
- 首版不启用注灵、旧灼烧来源、旧贯虹/破势和旧六强化；不因旧表存在而接回。
- 预览不改本体或随机状态；提交失败不半扣；达到截止先失败。已独立提交的药品不因后续超时而撤销。

### 3.2 精度与舍入

建议 HP、MP、伤害、护盾等数值用百分之一单位的安全整数存储，倍率用整数比例表示；一次独立效果完整乘算后，四舍五入到 0.01。禁止使用浮点连续累乘再随意取整。

- 例如 `6.30 × 115% = 7.245`，独立效果结算为 7.25。伤害抵盾/扣血只做同单位整数运算，不再分别舍入。
- 表格/界面最多两位小数，去掉末尾零；不能把 7.25 显示为 7 后宣称预览与执行一致。
- 剑势、耐久、回合、档位、MP 消耗配置仍是整数语义；整数 MP 消耗换算为相同存储单位再扣。
- 每一档强化的指定效果都须有可观察增量。若以后换算导致整档吞值，应调整获准测试表，不能偷偷保底加伤或改倍率。
- R03 跨零使用动作开始时的属性快照，整次主行动不因中途扣到零再换算一次。

## 6. R02-A：统一事件表建议

**下面精确顺序已获准测试，规则归属 02。** 以固定顺序实现，不按页面动画回调决定规则。

### 6.1 独立药品事务

1. 检查战斗/回合/修订令牌、截止、本回合尚未用药、斗法匣 UID、目标资源缺口。
2. 在副本上恢复实际 HP 或 MP、消费该实例，并标记本回合药品机会已用；不扣耐久、不改势/锋意/递锋衔接、不清盾、不推进意图/剑痕。
3. 保存成功后更新权威状态和修订号，仍是同一回合的主行动前。原主行动预览令牌失效，须用新状态重算。
4. 保存失败则保留上一有效状态和物品；再次点击不能消费第二次。已经成功提交后，取消主行动或主行动超时不能撤销药品。

阶段 1 获准只提供独立用药入口，不另做“药品+主行动组合提交”按钮，不改变现行允许定义组合事务的原则。

### 6.2 主行动事务

| 顺序 | 事件 | 处理建议与截断 |
| --- | --- | --- |
| E00 | 提交校验 | 校验快照令牌、阶段、截止、装配和 MP；纯规则预检无效行动，失败不扣资源 |
| E01 | 锁定本次属性并计费 | 用动作开始的 A/D/B 计算全部本次效果；扣 MP、按 R03 扣耐久；若是兑现出剑，锁定并消费原锋意/剑势 |
| E02 | 前置削盾 | 裂甲先减现有敌盾，不把剩余削盾转伤；符合条件立即触发一次崩甲 |
| E03 | 主动本体 | 普攻/攻击主动结算本体伤害，通用防御结算本体盾；养锋与凝锋增势统一在 E07；每次实际伤害后立刻检查死亡 |
| E04 | 本体附带盾 | 敌人仍存活时结算回澜本体盾；不乘锋意/被动；致死后不补做无关事件 |
| E05 | 锋意兑现 | 合法剑道攻击按 E01 锁定值结算一份附伤；非致死才继续敛芒、息锋待触发登记；不递归出新锋意 |
| E06 | 递锋、贯隙 | 按此顺序各结算一次符合条件的附伤，每次伤害后检查死亡；不再触发其他被动 |
| E07 | 养锋、剑痕与衔接记录 | 普攻/防御增势，合并初照/息锋后检查满势；凝锋实际增势并同步登记/应用本轮增强。留痕安装或刷新剑痕，登记本次主行动身份，各自只执行一次 |
| E08 | 旧敌盾到期 | 清掉供本次玩家主行动抵挡后剩余的旧敌盾；不是清除随后敌方意图新获得的盾 |
| E09 | 当前敌方意图 | 执行已经公开的意图，不重抽、不因贯隙打断；敌人新获盾保留供后续事件抵挡 |
| E10 | 存活检查与反击边界 | 玩家死亡立即失败，不跳剑痕求同归、不靠反击复活；只有另有获准来源才处理反击，每次伤害仍检查死亡 |
| E11 | 敌方阶段结束剑痕 | 敌我存活才结算一次剑痕，正常抵盾，扣剩余次数；致死即结束，不再生成下一意图 |
| E12 | 清盾与下一回合 | 清玩家本回合盾；不误清 E09 新敌盾。双方存活则下一回合、重置用药机会并确定/保存下一意图 |
| E13 | 原子保存 | 行动、HP/MP、耐久、库存、状态、意图、随机状态和结果一起提交；成功才播放事件，失败不发布临时结果 |

E03/E05 的致死仍保留本次合法行动的 MP/耐久消耗；临时战斗标记统一随结束清除，而不是回退费用。养锋与凝锋只在 E07 执行一次，不能先按基础增势生成锋意、再忘记本轮凝锋增强。E13 前还须按现行截止约定核对提交边界，动画耗时不能参与事件排序。

### 6.3 必须随顺序一起确认的细节

| 项目 | 建议裁决 |
| --- | --- |
| 崩甲来源 | 前置削盾、本体直接伤害、锋意附伤均可触发，合计每主行动一次；递锋/贯隙等被动附伤、剑痕、盾自然到期不触发，避免被动互相递归 |
| 本体已经击杀 | 不继续锋意伤害、被动得盾、挂剑痕或敌方行动；本次属于兑现出剑的锋意已在 E01 消费，结束时清临时状态 |
| 留痕第一次跳伤 | 安装瞬间不伤害；本次行动之后敌人存活并完成敌方阶段时，发生第一次跳伤，而非额外空等一整回合 |
| 同名剑痕刷新 | 改为新施放时的单次伤害和两次剩余结算，不叠层；非留痕行动不重算旧剑痕数值 |
| 剑痕与盾 | E09 新获得的敌盾可抵挡 E11 剑痕；剩余盾保留到下一玩家主行动，期间用药不会使其过期 |

| 蓄力识别 | 用明确意图标签，不用敌人名称、显示文案或旧 `interruptible` 猜测；阶段 1 不新增打断技能 |
| 反击 | 阶段 1 正式内容名单为空，不继承旧“守势反击”。仅可用纯规则测试夹具验证“存活后响应、每次伤害后截断”，不因此批准土道返震 |
| 玩家盾清除 | 所有本回合获准来源相加，承受敌方行动及合法反击后清除；药品事务不触发清除 |
| 完全无效施放 | 预检整个实际效果；满势凝锋禁止，缺蓝禁止，不以“还能扣耐久”当收益。较低但实际有效的伤害/盾/增势仍允许 |

## 7. R03：耐久与修补建议

### 7.1 R03-A，已获准测试

| 情况 | 建议 |
| --- | --- |
| 合法主行动 | 有武器且耐久大于零时扣 1，普攻、防御、攻击主动、凝锋均一致 |
| 已为零耐久 | 不扣成负数，不禁止行动，仅武器贡献为半值 |
| 本次从 1 变 0 | 整次主行动及本回合由它触发的效果使用动作开始时的完整武器属性；下次主行动使用半值 |
| 无武器 | 不虚构武器 ID/耐久，不扣武器耐久，使用角色基础 A/D |
| 用药/查看/无效施放/取消 | 不扣耐久 |
| 预览/保存失败 | 不改变正式耐久 |
| 跨战/新局/恢复 | 保留实际武器耐久，不自动修满；测试夹具重建不算正式补发 |
| 零耐久属性计算 | 先对武器贡献乘 0.5，再与角色基础相加，按 R01 精度一次换算；不是总伤害/总属性乘半 |

“每次 1”和“跨零本次按旧属性”已随本包获准测试，批准依据是用户决定，不是原实现。

### 7.2 R03-B，分期修补建议

建议局内基础修补道具每份恢复 20 耐久、上限截断、满耐久禁用；仅战外对已持有合法武器使用，消费一件实际物品，不占战斗主行动、不占战斗药品机会，仍计现实时间。无武器禁用，不借修补换装或改武器身份。

以上修补量和使用边界获准作为测试起点，阶段 1 不自动投放、赠送或生成该道具。拼图占格和携带空间随阶段 3 的 R06，地图掉落来源随阶段 4 的 R08；局外愿力修满的价格与交易随阶段 5 的 R09。不能为了单场测试新增免费维修或先定商店价格。

战斗中禁止换装；战外换装使用实际武器实例和合法空间，完整流转随阶段 3 验收，不借阶段 1 的空武器夹具冒充物品系统完成。所有装备失败掉落仍按 05，不新增铁剑保护。
