# 项目定位与版本范围

状态：已确认规则汇编；具体内容表与数值的待定范围见 [10](10_待补充内容与扩展提案.md)。

## 1. 游戏定位

《末法寻仙》是 2D 修仙题材搜打撤 RPG，结合固定站位回合制战斗、局内随机借法构筑、有限携带空间和局外永久成长。

核心体验是冒险、搜刮、取舍、撤离与成长。资源能否真正带回，比单纯清空敌人更重要；不靠打怪经验或普通打坐直接增加永久修为。

末法资源稀缺是总体背景。小说融合后，玩家为林澈，进入忆境探索历代至强道痕与历史残景，本源随关键忆境和剧情逐步找回。具体时代史实、首图地点和人物文案仍须对照小说源稿，不把早期策划或游戏技能提案当成小说正史。

## 2. 核心循环

局外整备实际武器与物资 → 入境并开始计时 → 随机两道 → 起始三选一取得一个主动 → 沿节点搜打、借法与管理物资 → 判断深入或前往撤离点 → 成功/失败结算实际物品 → 局外学习、出售、补给、修理和资源成长 → 下一局重新构筑。

永久保留的是技能学习资格、境界和本源等账号成长；两道、借到的主动被动、强化、技能点、道韵是本局临时内容。永久解锁只扩充合法池，不在下一局自动装配。

## 3. 首版范围

| 模块 | 当前范围 |
| --- | --- |
| 战斗 | 固定站位、一对一、敌人意图可见、每自身回合一次主行动 |
| 大道 | 先剑道与土道验证双道闭环，土道具体内容待批准；阵道后置 |
| 内容 | 炼气阶段剑道五主动六被动，少量通用被动；不要求十道齐全后再开测 |
| 地图 | 一张低阶历史残景，固定骨架加支路、完整探索八至十五战 |
| 搜打撤 | 三个随身空间、战后箱与搜索、恢复点、二至三撤离点、二十分钟 |
| 局外 | 愿力单币、每日有限商店与常备补给、书籍学习、维修、炼气小阶段 |
| 本源 | 优先少量功能与容错，具体能力与节点逐项设计 |
| 工程 | LayaAir 3.x、TypeScript、Excel/Luban 现有链路、独立新版测试档 |

旧方案中的“两张地图、四类武器、炼气九层到筑基、完整五行、丹毒炼丹”不再作为首版必做清单。具体武器类别、槽位和炼气阶段数量仍需内容表，不因旧名单自行扩张。

## 4. 已取消与暂缓

**不再沿用**：卡牌操作、战前配齐流派、实体/虚影双仓、手动化虚化实及转换费、铁剑专属失败保护、原型六强化与新版奖励并行、共鸣/碎片合成/重复书强化、自动发放旧贯虹破势。

**首版暂不启用**：注灵及属性石投放/出售、筑基新增与术式进阶效果、阵道正式扩展、十道全境界技能库、复杂炼丹、丹毒根基体系、完整本源剧情、玩家交易、多敌人、速度先攻、暴击闪避、通用技能冷却、战斗逃跑、广告续时、失败复活与救援。

暂缓不等于删除旧配置、素材、物品或存档；重新启用须有明确范围和规则确认。

## 5. 长期设计边界

大道负责规则特征；功法/传承负责技能归类与叙事；分支负责组合；境界限制承载上限；本源提供主角独有永久能力。不额外增加职业等级或整道许可证门槛。

技能库可延伸炼气、筑基、金丹、元婴、化神、炼虚、合道，但不机械要求每境界同样数量。独立低阶技能保留价值，同术式按当前合资格已解锁版本进入池。清浊道始终排除普通随机池，作为本源专题。

忆境来源不限于黄金纪元十位至强；先用线索和遗藏逐步揭示，不在开局揭露至强真相或终局。旧“废弃灵田”“青禾门”“古宗外院”等仅保留候选主题，未自动成为小说融合后的正式首图。

2026-11-10 用户另行明确首图场景选择“古宗山门外围”，不采用“雨仓镇”，也不写死“忆境荒林”。本次确认场景主题与可横向重复的地表背景，不等于批准宗门名称、人物、年代、线索、遗藏文案或改写小说正史；这些叙事内容仍留 R11。
