# 技能、装备与数值开发基线

日期：2026-11-23。版本：`combat-release-baseline-20261123`。

依据用户“把技能、装备、数值都确定下来，处理好并测试，要进入正式开发”的授权，本版收敛为首版正式开发输入。具体属性、特性区间及技能倍率不再以“之后再设计”留空；后续只针对实际缺陷和明确失衡调整。随后用户授权“帮我正式接入客户端”，本版已入Excel、经Luban生成并接入正式客户端。实际验证、技能来源与长期系统边界见[客户端接入记录](客户端接入记录.md)。存档不自动迁移或清除，配置不匹配保留原文并要求明确重建。

本文件负责联合标准；[技能正文](../功法设计/自由技能设计_搜打撤标准.md)负责34项技能的具体操作含义；[开发参数表](开发参数表.md)和[开发数值JSON](开发数值.json)负责本版精确参数。旧装备稿前14节和前两轮自由组合实验均属历史，不能混用药品占行动、额外战术转换或三行动规则。

## 1. 本版确定的配置

| 项目 | 开发标准 |
| --- | --- |
| 属性 | 生命、法力、物理攻击、精神力、护甲、速度，共六项 |
| 裸装起点 | 240生命、36法力、18物理攻击、18精神力、6护甲、10速度 |
| 主动技能 | 最多装配5项；普攻、防御始终可用，不占这5项 |
| 技能库 | 34项主动，物理/魔法/混合分段读取各自属性，辅助按实际效果读取 |
| 装备 | 武器、防具、饰品各1件，共24底材、六品质 |
| 每件装备 | 固定主属性种类；随机主属性值、随机副属性种类与值、随机1条特性 |
| 特性 | 每部位8条，共24条；藏锋等原六条已纳入装备池，没有额外被动栏 |
| 行动 | 每存活单位每回合1次；速度在开战锁定顺序，同速玩家优先，敌人同速按生成顺序 |
| 战内用药 | 自身出招前可用1份，血蓝药共用次数，不占行动；每格1份，共5格，不能战内补匣 |
| 标准药效 | 血药90、蓝药18；过量作废，药引仅提高本份实际药效 |
| 连续探索 | 保留实际血蓝、药品、装备耐久；没有自动补满 |
| 战斗临时值 | 护盾、状态、冷却、每战次数、攻击计数、藏锋/存锋/换脉等在战后清除 |
| 探索累计值 | 嗜血和百战计数跟随实际装备，离境/失败清除；不是永久养成 |

用户最新明确只保留5个主动技能位，覆盖此前8格提案。五格用于限制“全部恢复与爆发技能无代价同时携带”，允许跨体系自由组合；技能库仍保留34项。学习来源仍按整本功法组织，不拆成34本单招书；本次数值验证假设示例技能已可装配，不将示例套装或药品当作永久初赠。

主矩阵使用标准血蓝药。现有玉露丹改为150血、凝神丹30蓝、调息散45血加9蓝、护元散45盾；六种药均为一格一份，另有六药组合专项验证。药引提高血蓝恢复，不提高护盾药；双回药任一资源有缺口即可使用。体力药保留原探索用途，不进药匣。物品身份与ID保持，禁止把旧420血、50蓝直接带入新低面板。

## 2. 属性与装备预算

品质允许档位固定为普通1～3、优秀1～4、精良2～5、稀有3～5、史诗3～6、传说4～6。主、副各自先等概率抽档，再在档内均匀抽整数；副属性在六属性中等概率抽取，可与主属性重复。品质不额外乘一次属性倍率。

本轮将旧装备血量主属性最高180、副属性最高80收紧到80/40，法力主副最高15/8；攻击和精神力主副最高13/6，护甲最高8/5，速度副属性最高3。这样装备能改变打法，又不让角色主要依靠成倍血量压过技能选择。精神力与物理攻击使用相同属性预算，速度只决定顺序，首批底材不分配速度主属性。

目前24底材允许的理论静态面板单项上限：

| 属性 | 裸装 | 三件贡献上限 | 合计上限 |
| --- | --- | --- | --- |
| 生命 | 240 | 280 | 520 |
| 法力 | 36 | 69 | 105 |
| 物理攻击 | 18 | 44 | 62 |
| 精神力 | 18 | 44 | 62 |
| 护甲 | 6 | 39 | 45 |
| 速度 | 10 | 9 | 19 |

以上是各属性分别极端专精的上限，同一套无法同时拿满；临时启明、百战等另按特性上限处理，仍不会把攻击/护甲推成三位数。护甲同时影响两种伤害，精神力不默认提供穿甲；法力上限不直接转为法术伤害。

流云扇、青竹杖、玄山印和凝神簪改以精神力为主属性，玄铜铃为法力。其他底材具体主属性、重量、耐久见参数表。相同预算的不同器型可保留外观差异，不暗加攻速或多次行动。

## 3. 特性与技能怎样组合

| 路线 | 武器 / 防具 / 饰品特性 | 五技能 |
| --- | --- | --- |
| 放血省药 | 识隙 / 血饲 / 节用 | 裂帛、断甲刺、饮血刃、截脉、血偿 |
| 养火收火 | 余烬 / 护体 / 藏锋 | 点烬、焚尽、焚风、火息、灰烬衣 |
| 寒意择机 | 猎弱 / 养元 / 换脉 | 凝霜、碎寒击、回霜、霜封、横扫 |
| 雷印调度 | 叠锋 / 守势化锋 / 调息 | 雷引、惊雷、雷回流、霆护、雷链 |
| 守势转攻 | 饮血 / 守势化锋 / 藏锋 | 铁衣、守反、碎壁轰、饮血刃、断甲刺 |
| 血蓝轮换 | 饮血 / 血饲 / 换脉 | 燃血、血契、饮血刃、化灵、涤尘 |

这些是同预算验证样本，不是职业或固定套装。首批三个特性池完全不重名；同名来源未来同时存在时只取收益高、同收益门槛低的一条，未生效条目不累计计数。仅实际出现重复才提示。

高品质主要提高P收益，部分特性同时降低N门槛。识隙普通每3次破甲物理命中给1层流血，史诗每次即可；余烬普通需消费5层灼烧，史诗需3层。合律始终要求三种不同技能，保留轮换意义。节用最高返3蓝，但每战最多5次，不能把全部低耗技能永久变成免费。

原回风、凝雷、铁衣装备特性、续命、灵息、静虑、定心退出本版24条池；对应槽位由状态联动、原六被动及调息等替代。技能“铁衣”保留。嗜血、百战保留探索成长，叠锋保留攻击计数，药引保留补给特化。

## 4. 结算顺序

1. 开战一次合并三件属性，锁定速度顺序与本场耐久状态。更快敌人先行动，存活才到玩家用药机会。
2. 玩家回合开始清除上次防御、守反、固守，结算调息；药品只恢复资源，不推进冷却、状态、攻击计数或技能轮换。
3. 出招前校验技能、目标、前置法力、生命支付、冷却、材料、净化选择和可选雷印消费。失败不扣费；合法出招先付费，再锁定本招属性与增幅。
4. 物理和魔法逐段计算。原始伤害先合并同类增幅与适用的直接减伤，再按`原伤害×100/(100+护甲)`四舍五入、正数最低1，之后扣盾，再扣生命。敌人防御不降低持续伤害。
5. 整招本体完成后，按本体实际扣除生命汇总吸血；不计护盾、溢出、持续伤害、伏雷爆炸、反击和特性附伤。整招最多推进一次命中/攻击计数；群体吸血可汇总原技能对各目标的实际生命伤害。
6. 处理识隙、叠锋、存锋附伤、节用、合律等。附伤不递归触发特性；嗜血本次达到启动击杀数时，不追溯增强本次吸血。
7. 敌方完整主动攻击后，玩家存活才触发护体、反震、守反。多段不能靠受击后护盾挡掉同一次攻击的后续段；反震每次自身出招间隔一次，守反每次施放一次。
8. 最后一名敌人死亡后，当前招式随附吸血/返蓝仍完成，随后结算一次胜利恢复和耐久；不继续敌方行动或轮末伤害。玩家死亡优先判失败，不能被反击/吸血救活。
9. 双方存活才到轮末：玩家持续状态先结算，随后敌人按生成序结算；出现死亡立即检查战果。各层单独减剩余次数，之后进入下一完整回合。

正恢复量四舍五入后截断缺口，不设最低1；明确的向上/向下取整遵照技能正文。流血禁疗作用于所有生命恢复，包括药品和吸血；胜利恢复发生在清除战斗状态前。护盾总上限为生命上限30%，血饲还受来源额度约束；主动花盾不产生存锋。破盾翻倍只作用盾，溢出回算后才能伤生命。

寒意每层降低直接伤害6%；“下一次攻击压制”与寒意乘算，覆盖下一次主动攻击所有直接伤害段，不影响持续伤害。同类只保留尚未过期的最高压制，最迟下回合末失效。

标准八战路线为游兵、斥候、重甲统领、铁甲守卒、霜纹侍者、结界执事、持符卫士、镇门石卫；每完成3战，后续生命预算+10%、双攻+4%，最多2档。正式地图按战斗序号读取同一压力规则，不把敌人模板面板再乘一次品级倍率。

本轮针对首领总承伤过高，将三首领生命由460/420/490调整到360/340/380，并将首领产盾次数从3降至2；不降低重击威胁。普通/精英基础面板未因此整体变弱。

## 6. 耐久、修理与实例

普通/精英/首领每场结束分别扣武器、防具、饰品`2/2/1`、`3/3/2`、`5/5/3`。按本场最高敌人档次扣一次，不按受击次数或敌人数量叠扣。本场开始非零则完整生效；本场扣零，下一场主副属性贡献减半，被动保持完整。

同件同属性先合并再减半并四舍五入。换装或修理提高血蓝上限不补当前值，上限下降只截断当前值。正式保存中记录装备实例的主副档位与数值、特性参数、耐久、探索击杀累计；穿脱、读档、修理不重抽。

战外拖修理物到装备松手修理；整备/炼器室一键修理当前三件，愿力不足整笔不执行。每恢复1耐久的六品质费用为1/1/2/2/3/4愿力；实际沿用307砥锋石恢复12耐久、308养铁匣修满1件，保留已有物品身份，草案中的养器砂/温养匣不另建同功能物品。

## 7. 测试和放行口径

真实命令、样本数量和结果见[测试报告](测试报告.md)，逐场记录见[逐回合战报](逐回合战报.md)。本版验证的是技能、装备、行动、整数结算、实际药匣与连续资源的联合规则，自动策略胜率不等于真人胜率。

候选比较使用种子17/118；正式扩大使用733/941；底材/特性专项使用2027/5821；群体、低资源、零耐久与随机特性使用3049/4093。各组按完全相同物品和敌人输入对照，不通过重抽低值装备挑成绩。

单场同时报告无药与首领五格补给。八战同时报告仅初始五格、战外补满、节约补给三种情况。后两种各额外带10血药/8蓝药，共18格，放入固定精良纳虚器21格；其余3格保留工具或拾取空间。各示例装备、背包本体与18份药的重量不超过精良纳虚器34承重上限；装备品质与背包品质分开，不假设白装必须背白包。

额外药品只有战外才能使用或补入药匣；全过程不凭空补资源。节约策略只在缺口达到药效65%时战外用药，补满策略只要有缺口就用；两者是自动策略对照，不是游戏强制门槛。不模拟地图药品掉落、修理途中收益、拾取/负重实时变化或经济净收益，不将18份储备描述为常规免费补给。

本版普通战目标约3～5回合、精英约5～9回合、首领约9～16回合；极端装备、克制或防守路线可以偏离，不写入最低回合、伤害上限或强制斩杀规则。首版可用性重点是六条路线均能运作、补给有实际用途、无资源复制与触发递归，不要求所有白装无药通关。

### 五格复核结论

用户要求缩为5格并连同数值一起检查后，六套示例全部重新选择五招，联合矩阵重新生成，不沿用八格成绩。裸装属性、装备主副区间及24条特性参数、34技能倍率/费用、六药药效、敌人面板与耐久费用均保留当前值，不为少三个技能位整体增伤或削敌。

本轮104组规则、6912次装备生成检查通过，共记录7689场验证战斗，无停滞。普通/精英无药矩阵分别1008/1008、720/720，胜场平均4.16/7.77回合；首领无药305/432、平均12.26回合，带五份标准药428/432、平均12.67回合。四场带药首领失败均为白/绿品质、种子941的保守策略对焚殿长老；保留失败，不以所有低品质组合必胜为定版要求。

有限储备、节约补给的八战路线完成128/144，血/蓝药实际使用均值6.67/6.31份；白到红品质分别18/24、18/24、21/24、23/24、24/24、24/24。失败均发生于最终首领，涉及续航和配药取舍。守势路线无药首领胜场平均17.59回合，超过总体目标但血药消耗更低，保留防守型组合的时间代价。以上仅覆盖指定种子、固定六套组合与自动策略；不能解释为真人胜率或所有五技能组合的平衡保证。

## 8. 正式接入要求与状态

1. 在现有战斗模块实现纯规则核、命令/预览共用结算，再由现有探索事务管理器接入；不把独立验算目录直接当正式运行配置。
2. 2026-11-24 按用户要求，配置按战斗、技能、敌人、物品、装备、储物、地图七类维护。数值枚举和只读名称列按09号工程约定；基础物品仅放公有字段，装备六张专属子表独立为`装备配置表.xlsx`，药效归物品专属表，技能效果归技能专属表。所有数据行按固定ID数值升序插入，旧物品`101–108`已删除退役、不得复用，起始武器改为优秀青钢剑`110`。
