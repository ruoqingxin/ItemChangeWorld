# 废弃灵田秘境设计

> 项目：《末法寻仙》  
> 秘境名称：废弃灵田  
> 文档版本：V0.1  
> 定位：新手秘境 / 炼气前期资源点 / 核心玩法教学场

---

## 一、秘境定位

"废弃灵田"是玩家接触的第一个正式秘境。

它承担以下作用：

1. 教会玩家基础探索
2. 教会玩家拾取资源
3. 教会玩家背包空间管理
4. 教会玩家基础战斗
5. 教会玩家使用五行属性石附魔
6. 教会玩家武器耐久消耗
7. 教会玩家撤离机制
8. 提供炼气前期成长资源

---

## 二、背景设定

废弃灵田原本是上古小宗门"青禾门"的外门药田。

末法大劫后，青禾门灵脉枯竭，宗门覆灭，灵田被遗弃。

多年后，灵田深处仍残留少量地脉灵机，因此偶尔会生长低阶灵草，也吸引了大量被灵气污染的低阶妖兽。

如今这里成为散修和低阶修士最常进入的秘境之一。

---

## 三、推荐境界

| 项目 | 配置 |
| --- | --- |
| 最低进入境界 | 炼气一层 |
| 推荐境界 | 炼气一层 ~ 炼气五层 |
| 高收益挑战境界 | 炼气六层以上 |
| 主要产出 | 低阶灵草、1 级属性石、劣品灵石 |
| 难度定位 | 新手 / 低风险 |

---

## 四、秘境核心体验

废弃灵田的核心体验是：

> **在低风险环境中学习"搜刮—战斗—取舍—撤离"的完整循环。**

玩家应在这里逐步理解：

- 不是所有怪都必须打
- 附魔很强，但会消耗属性石和武器耐久
- 背包空间有限，不能什么都带走
- 成功撤离才算真正获得资源
- 直接吞服和带出炼丹有不同收益

---

# 五、地图结构

## 1. 地图类型

建议使用：

```text
半随机房间式地图
```

即：

- 主路径固定
- 房间内容随机
- 撤离点位置半随机
- 资源点随机刷新
- 精英怪房间低概率出现

## 2. 地图区域

废弃灵田由以下区域组成：

| 区域 | 说明 |
| --- | --- |
| 入口区 | 玩家出生点，安全区域 |
| 外围田埂 | 低阶怪物和基础采集点 |
| 枯井区 | 有少量宝箱和隐藏资源 |
| 药田残区 | 主要灵草产出点 |
| 妖兽巢穴 | 怪物密度较高 |
| 破损阵台 | 可作为撤离点或事件点 |
| 灵田深处 | 精英怪和高价值资源 |

## 3. 推荐地图流程

```text
入口区
↓
外围田埂
↓
药田残区
↓
枯井区 / 妖兽巢穴
↓
灵田深处
↓
撤离点
```

玩家可以提前撤离，也可以继续深入挑战高价值区域。

# 六、区域详细设计

## 1. 入口区

**作用：**

- 玩家出生点
- 无敌人
- 提供基础提示
- 让玩家整理初始状态

**内容：**

- 破旧界碑
- 秘境提示文字
- 简单采集点 1 个
- 低概率刷新劣品灵石

**教学提示：**

```text
此地灵气稀薄，无法自然修炼。
若想提升境界，需搜寻天材地宝并成功撤离。
```

## 2. 外围田埂

**作用：**

- 第一次战斗区域
- 怪物弱
- 资源低价值
- 教会玩家普攻和拾取

**可能出现：**

| 内容 | 数量 |
| --- | --- |
| 腐化灵鼠 | 2-4 只 |
| 低阶灵草丛 | 1-2 处 |
| 劣品灵石 | 0-2 个 |
| 破旧木箱 | 0-1 个 |

## 3. 药田残区

**作用：**

- 主要采集区域
- 让玩家获得天材地宝
- 引导玩家理解吞服和炼丹

**可能出现：**

| 内容 | 数量 |
| --- | --- |
| 青玉灵果 | 1-2 个 |
| 赤炎草 | 1-2 株 |
| 低阶灵草 | 2-4 株 |
| 腐化灵鼠 | 2-3 只 |
| 赤眼妖兔 | 1-2 只 |

## 4. 枯井区

**作用：**

- 小型风险奖励区域
- 有宝箱
- 可能遭遇伏击

**可能出现：**

| 内容 | 数量 |
| --- | --- |
| 破损宝箱 | 1 个 |
| 腐化灵鼠 | 2 只 |
| 枯藤精 | 0-1 只 |
| 劣品灵石 | 1-3 个 |

**特殊事件：**

玩家打开宝箱时，有概率触发：

| 事件 | 概率 |
| --- | --- |
| 正常开启 | 70% |
| 毒雾陷阱 | 20% |
| 小怪伏击 | 10% |

## 5. 妖兽巢穴

**作用：**

- 战斗压力区
- 属性石主要产出点
- 鼓励玩家使用附魔

**可能出现：**

| 内容 | 数量 |
| --- | --- |
| 赤眼妖兔 | 2-4 只 |
| 枯藤精 | 1-2 只 |
| 腐化灵鼠 | 2-3 只 |
| 小型宝箱 | 1 个 |

**掉落倾向：**

- 1 级火属性石
- 1 级木属性石
- 劣品灵石
- 低阶妖丹碎片

## 6. 破损阵台

**作用：**

- 撤离点候选区域
- 教会玩家消耗灵石撤离

**机制：**

破损阵台可能有两种状态：

| 状态 | 说明 |
| --- | --- |
| 可用 | 可直接撤离 |
| 失灵 | 需要消耗劣品灵石激活 |

**激活条件：**

```text
消耗：劣品灵石 × 3
激活时间：5 秒
激活期间若受到攻击，会被打断
```

## 7. 灵田深处

**作用：**

- 高风险高收益区域
- 精英怪所在区域
- 高品质资源点

**进入提示：**

```text
前方灵气异常波动，似有强大妖兽盘踞。
继续深入可能获得珍贵资源，也可能无法安全撤离。
```

**可能出现：**

| 内容 | 数量 |
| --- | --- |
| 灵田守卫 | 1 只 |
| 青玉灵果 | 1-2 个 |
| 地脉玉髓 | 0-1 个 |
| 精致宝箱 | 1 个 |
| 撤离点 | 0-1 个 |

# 十、撤离点设计

## 1. 固定撤离点

**特点：**

- 地图中固定区域可能刷新
- 无需额外条件
- 新手最容易理解

## 2. 破损阵台撤离点

**特点：**

- 需要消耗灵石激活
- 激活过程可被打断
- 提供一定紧张感

**配置：**

| 项目 | 数值 |
| --- | --- |
| 激活消耗 | 劣品灵石 × 3 |
| 激活时间 | 5 秒 |
| 被攻击是否打断 | 是 |
| 使用次数 | 1 次 |

## 3. 临时裂隙撤离点

MVP 可以暂不做。

后续版本可以加入：

- 随机出现
- 持续时间有限
- 不需要灵石
- 但位置危险

# 十一、秘境事件

## 1. 灵气残涌

**效果：** 玩家进入一片灵气残留区域。

**可选择：**

| 选项 | 效果 |
| --- | --- |
| 吸收灵气 | 恢复少量灵力，但增加少量杂质 |
| 放弃 | 无效果 |

## 2. 腐朽丹炉

**效果：** 发现上古废弃丹炉。

**可选择：**

| 选项 | 效果 |
| --- | --- |
| 搜索 | 获得丹药或药渣 |
| 注入灵力 | 有概率获得丹方碎片 |
| 离开 | 无效果 |

## 3. 破碎阵旗

**效果：** 可作为撤离点线索。

**可选择：**

| 选项 | 效果 |
| --- | --- |
| 修复 | 消耗灵石，标记最近撤离点 |
| 拆解 | 获得材料 |
| 离开 | 无效果 |

# 十二、教学引导

## 1. 第一次获得属性石

**提示：**

```text
你获得了一颗五行属性石。
属性石可在攻击前为武器附魔，造成额外伤害。
附魔会消耗武器耐久。
```

## 2. 第一次武器耐久降低

**提示：**

```text
武器灵纹受到损耗。
耐久归零后，武器将无法继续附魔。
```

## 3. 第一次背包满

**提示：**

```text
储物袋已满。
你需要丢弃部分物品，或立即寻找撤离点。
```

## 4. 第一次获得天材地宝

**提示：**

```text
天材地宝可以直接吞服获得修为，
也可以带出秘境炼制丹药，获得更高收益。
```

## 5. 第一次发现撤离点

**提示：**

```text
发现撤离阵台。
成功撤离后，背包中的资源才会真正归你所有。
```

# 十四、废弃灵田验收标准

完成该秘境后，玩家应能体验：

1. 进入秘境
2. 击败基础怪物
3. 采集低阶灵草
4. 获得属性石
5. 使用属性石附魔攻击
6. 看到武器耐久下降
7. 获得天材地宝
8. 背包满时进行取舍
9. 找到撤离点
10. 成功带出资源
11. 撤离后吞服或炼丹提升修为
