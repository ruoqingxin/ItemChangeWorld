# 背包与搜打撤系统

> 项目：《末法寻仙》  
> 文档版本：V0.1  
> 目标：定义局内探索、背包取舍、死亡损失和撤离规则

---

## 一、系统定位

背包系统是本游戏搜打撤体验的核心。

它不是普通仓库，而是玩家每次进入秘境前后都要做决策的核心系统。

玩家必须在有限空间中平衡：

- 战斗资源
- 生存补给
- 撤离收益
- 高价值战利品
- 备用武器
- 属性石
- 灵石

---

# 二、核心循环

```text
局外整理背包
↓
携带武器 / 灵石 / 属性石 / 丹药
↓
进入秘境
↓
搜刮资源
↓
背包逐渐填满
↓
遇到更高价值物品
↓
丢弃低价值物品或撤离
↓
成功撤离
↓
资源进入仓库
```

# 三、背包规则

## 1. 背包形式

采用格子背包。

MVP 默认背包：

```text
6 × 5 = 30 格
```

后续可通过更高品质储物袋扩展。

## 2. 物品占格

| 物品类型 | 占格 |
| --- | --- |
| 小型材料 | 1 格 |
| 属性石 | 1 格，可堆叠 |
| 丹药瓶 | 1 格，可堆叠 |
| 灵石袋 | 1 格，可堆叠 |
| 匕首 | 1×2 |
| 长剑 | 1×4 |
| 大刀 | 2×4 |
| 法杖 | 1×4 |
| 大型天材地宝 | 1×2 或 2×2 |

## 3. 物品旋转

MVP 建议：

```text
暂不支持物品旋转。
```

后续可加入：

```text
支持 R 键旋转物品。
```

## 4. 堆叠规则

### 属性石堆叠

同以下条件才可堆叠：

- 同五行
- 同等级
- 同纯度档

例如：

```text
火属性石 / 1级 / 普通
可以堆叠。
```

但：

```text
火属性石 / 1级 / 精纯
需要另占一格。
```

### 丹药堆叠

同种丹药可堆叠。

建议：

```text
最大堆叠数量：10
```

### 灵石堆叠

同品质灵石可堆叠。

建议：

```text
最大堆叠数量：99
```

# 四、局外准备

## 1. 玩家可携带内容

进入秘境前，玩家可选择携带：

| 类型 | 作用 |
| --- | --- |
| 主武器 | 主要战斗工具 |
| 备用武器 | 主武器耐久耗尽后的保底 |
| 属性石 | 附魔攻击资源 |
| 灵石 | 回复灵力、激活撤离点 |
| 丹药 | 回复生命、灵力或临时强化 |
| 修复道具 | 局内恢复武器耐久 |
| 空背包空间 | 用于携带战利品 |

## 2. 准备阶段核心决策

玩家需要考虑：

- 多带属性石，战斗强，但背包空间少
- 多带灵石，续航强，但收益空间少
- 多带武器，更安全，但影响搜刮
- 少带补给，收益空间大，但死亡风险高

# 五、局内拾取

## 1. 拾取规则

当玩家接触掉落物时：

- 如果背包有空间，直接拾取
- 如果背包无空间，提示背包已满
- 玩家可打开背包进行整理或丢弃物品

## 2. 背包满提示

```text
储物袋已满。
请选择丢弃部分物品，或寻找撤离点。
```

## 3. 价值提示

后续可加入物品价值提示：

| 颜色 | 价值 |
| --- | --- |
| 灰色 | 低价值 |
| 白色 | 普通 |
| 绿色 | 可用 |
| 蓝色 | 较高 |
| 紫色 | 稀有 |
| 橙色 | 高价值 |

# 六、撤离系统

## 1. 撤离意义

只有成功撤离，背包中的资源才会真正归玩家所有。

死亡会导致本局资源大部分损失。

## 2. 撤离点类型

| 类型 | 说明 |
| --- | --- |
| 固定撤离点 | 固定位置，稳定撤离 |
| 条件撤离点 | 需要灵石、钥匙或击败怪物 |
| 临时撤离点 | 随机刷新，限时存在 |
| 高阶撤离点 | 高境界后可感知或开启 |

## 3. MVP 撤离点

MVP 先做两种：

### 固定撤离点

- 玩家站在撤离区域内
- 读条 5 秒
- 期间受伤会打断
- 读条结束成功撤离

### 破损阵台

- 需要消耗劣品灵石
- 激活后读条撤离

配置：

| 项目 | 数值 |
| --- | --- |
| 灵石消耗 | 3 |
| 读条时间 | 5 秒 |
| 受击打断 | 是 |

---

# 七、死亡损失

## 1. 死亡基础规则

玩家在秘境中死亡时：

- 本局背包内未绑定物资全部丢失
- 已消耗的属性石不返还
- 已消耗的灵石不返还
- 武器耐久损耗保留
- 本局未撤离资源不进入仓库

## 2. 保底保留

为了降低挫败感，MVP 可以保留：

| 内容 | 是否保留 |
| --- | --- |
| 玩家境界 | 保留 |
| 局外仓库 | 保留 |
| 已学丹方 | 保留 |
| 怪物图鉴 | 保留 |
| 地图见闻 | 部分保留 |
| 本局已吞服修为 | 保留 50% |

## 3. 可选温和规则

如果想降低难度：

```text
死亡后随机保留背包中 1 件非任务物品。
```

或者：

```text
死亡后可花费灵石赎回部分遗失物。
```

MVP 可以暂不做。

# 八、收益结算

## 1. 成功撤离结算

成功撤离后显示：

- 本局击杀怪物数量
- 获得灵石
- 获得属性石
- 获得天材地宝
- 获得武器装备
- 获得丹方
- 获得总价值
- 武器耐久损耗
- 消耗属性石数量

## 2. 死亡结算

死亡后显示：

- 死亡原因
- 损失物品
- 已消耗资源
- 保留内容
- 地图探索进度
- 下次建议

| 精英怪概率 | 提高 |
| 陷阱概率 | 提高 |
| 背包压力 | 提高 |

# 十、玩家决策示例

玩家背包剩余 2 格，发现：

- 青玉灵果，占 1 格
- 地脉玉髓，占 2 格
- 1 级火属性石，占 1 格

玩家需要选择：

- 丢弃低价值灵草，带走地脉玉髓
- 放弃地脉玉髓，带走两个小物品
- 直接吞服青玉灵果，腾出空间
- 立即撤离，不再冒险
