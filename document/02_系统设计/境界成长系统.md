# 境界成长系统

> 项目：《末法寻仙》  
> 文档版本：V0.1  
> 目标：定义末法时代下的修为获取、境界提升、突破品质和成长限制

---

## 一、系统定位

境界系统不是传统等级系统。

本游戏设定在末法时代，玩家无法通过打坐或打怪自然增加修为。

玩家必须进入秘境，获得天材地宝、丹药、妖丹等资源，将其转化为修为。

---

# 二、核心规则

## 1. 不靠打怪升级

怪物本身不直接提供修为经验。

怪物提供：

- 属性石
- 妖丹
- 灵石
- 天材地宝
- 突破材料
- 丹方
- 武器

玩家成长来自这些资源的后续转化。

---

## 2. 修为来源

修为主要来自：

| 来源 | 说明 |
| --- | --- |
| 直接吞服天材地宝 | 快速但有丹毒和杂质 |
| 服用丹药 | 效率更高，副作用更低 |
| 吸收妖丹 | 高收益但风险高 |
| 使用古修灵液 | 稀有资源 |
| 完成突破试炼 | 可能获得境界加成 |

---

# 三、境界结构

## 1. 初版大境界

游戏初版规划五个大境界：

1. 炼气
2. 筑基
3. 金丹
4. 元婴
5. 化神

---

## 2. MVP 境界范围

MVP 只做：

- 炼气一层到炼气九层
- 筑基初期

---

# 四、炼气境设计

## 1. 定位

炼气境代表玩家刚刚踏入修仙道路。

在末法时代，炼气不是吸收天地灵气，而是学习如何使用外来灵力。

---

## 2. 小阶段

| 阶段 | 说明 |
| --- | --- |
| 炼气一层 | 初入修行 |
| 炼气二层 | 能稳定运转灵力 |
| 炼气三层 | 可使用基础附魔 |
| 炼气四层 | 灵力上限提升 |
| 炼气五层 | 可进入更深秘境 |
| 炼气六层 | 战斗能力增强 |
| 炼气七层 | 可挑战古宗外院 |
| 炼气八层 | 筑基准备阶段 |
| 炼气九层 | 炼气圆满，可突破筑基 |

---

## 3. 修为需求建议

| 境界 | 升级所需修为 |
| --- | ---: |
| 炼气一层 → 二层 | 100 |

| 炼气四层 → 五层 | 300 |
| 炼气五层 → 六层 | 400 |

| 炼气七层 → 八层 | 650 |

# 五、筑基境设计

## 1. 定位

筑基是修士第一次真正建立稳定修行体系。

末法时代中，筑基代表玩家将外来资源转化为自身根基。

---

## 2. 筑基品质

| 品质 | 条件 | 效果 |
| --- | --- | --- |
| 残基 | 丹毒高、根基低 | 属性较低，后续突破困难 |
| 凡基 | 普通条件达成 | 标准筑基 |
| 灵基 | 丹毒较低，根基较好 | 灵力上限提高 |
| 地基 | 高品质筑基材料 | 灵石转化效率提高 |
| 天基 | 低丹毒、高根基、稀有材料 | 获得特殊被动 |

---

## 3. 筑基条件

| 条件 | 说明 |
| --- | --- |
| 炼气九层修为满 | 必须条件 |
| 筑基丹 | 主要突破材料 |
| 地脉玉髓 | 影响筑基品质 |
| 丹毒低于阈值 | 丹毒过高会降低成功率 |
| 根基稳定度达标 | 影响突破品质 |

---

# 六、修为获取

## 1. 直接吞服

天材地宝可直接使用。

### 示例

| 物品 | 直接修为 | 丹毒 | 杂质 |
| --- | ---: | ---: | ---: |
| 低阶灵草 | 30 | 2 | 1 |
| 青玉灵果 | 80 | 5 | 3 |
| 赤炎草 | 60 | 6 | 4 |
| 地脉玉髓 | 200 | 10 | 5 |

---

## 2. 炼丹服用

炼丹后修为收益更高，丹毒更低。

### 示例

| 丹药 | 修为 | 丹毒 |
| --- | ---: | ---: |
| 聚气丹 | 100 | 2 |
| 青玉培元丹 | 140 | 1 |
| 赤炎养气丹 | 130 | 2 |
| 筑基丹 | 突破材料 | 5 |

---

# 七、丹毒与杂质

## 1. 丹毒

丹毒来源：

- 直接吞服天材地宝
- 服用低品质丹药
- 强行吸收妖丹

丹毒影响：

- 降低突破成功率
- 降低筑基品质
- 可能触发负面状态

---

## 2. 杂质

杂质来源：

- 低品质资源
- 未炼化材料
- 反复直接吞服

杂质影响：

- 降低根基稳定度
- 降低同境界属性倍率
- 增加后续清理成本

---

## 3. 清理方式

| 方式 | 作用 |
| --- | --- |
| 清毒丹 | 降低丹毒 |
| 培元丹 | 提高根基 |
| 闭关净化 | 消耗灵石和时间清除杂质 |
| 高品质丹药 | 减少新增丹毒 |

---

# 八、根基系统

## 1. 根基定义

根基代表玩家修为是否稳定、纯净、适合突破。

根基越高：

- 突破成功率越高
- 突破品质越高
- 同境界属性越强
- 后续境界上限越高

---

## 2. 根基影响因素

| 行为 | 影响 |
| --- | --- |
| 直接吞服低质材料 | 降低根基 |
| 炼丹服用 | 维持或提高根基 |
| 使用培元类丹药 | 提高根基 |
| 丹毒过高 | 降低根基 |
| 完成试炼 | 提高根基 |
| 使用高品质突破材料 | 提高根基 |

---

# 九、突破流程

## 1. 小境界提升

小境界提升流程：

```text
修为满
↓
点击突破 / 自动提升
↓
消耗少量灵石
↓
进入下一小阶段
```

MVP 中小境界可以简化处理。

## 2. 大境界突破

大境界突破必须满足条件：

```text
修为圆满
↓
突破材料齐全
↓
丹毒未超标
↓
根基稳定
↓
进行突破判定
↓
生成突破品质
↓
进入下一大境界
```

## 3. 筑基突破结果

可能结果：

| 结果 | 说明 |
| --- | --- |
| 失败 | 材料部分损失，角色虚弱 |
| 残基 | 勉强成功，品质较差 |
| 凡基 | 正常筑基 |
| 灵基 | 较好筑基 |
| 地基 | 高品质筑基 |
| 天基 | 完美筑基 |

| 境界 | 解锁内容 |

| 炼气三层 | 五行附魔 |

---

# 十一、MVP 验收标准

完成后应支持：

- 玩家吞服资源增加修为
- 玩家服用丹药增加修为
- 玩家修为满后提升小境界
- 丹毒会随吞服增加
- 炼丹比直接吞服收益更高
- 炼气九层可尝试筑基
- 筑基根据根基和丹毒生成品质
