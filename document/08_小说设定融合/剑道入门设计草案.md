## 1. 讨论范围

- 从青冥剑尊的剑道方向切入，本篇记录入门道性与一个主动技能的配合，不作为完整炼气技能库。
- 仅以当前铁剑和剑势为例，不限制长期剑道技能库，也不规定其他大道使用剑势。
- 用户已认可“养锋 + 裂甲斩”的核心方案可用于炼气阶段，不表示这是炼气阶段的全部剑道技能。
- 已确认核心：蓄满三层剑势获得一次锋意，下一次消耗剑势的攻击兑现额外剑伤；锋意最多一次、不在满势时反复获得、战斗结束清除。裂甲斩负责破盾，与贯虹的直接伤害、破势的打断分工。
- 具体伤害、削盾量、暂议的两层消耗及其他未确认细则仍待讨论；认可设计不代表批准开发。
- 此前“非攻击行动后强化下次攻击”的养锋仅为分工示例，以本篇已确认的满势触发方案为准，不将两套触发方式叠加。
- 筑基及以上境界的道性演变与具体新技能另行设计；用户已认可低阶技能跨境界仍可借用，通过角色能力成长、独特定位与技能书进阶保留价值，具体公式与术式效果待定。
- 用户已认可[《剑道炼气技能库草案》](剑道炼气技能库草案.md)中的第一批五主动、六被动方向，以及借法主动最多三个、被动不限数量等规则；炼气默认临借与书籍解锁分工随后也已确认，见《剑道技能体系与境界安排草案》，其中筑基承接仍为待确认提案。

## 2. 核心取舍

两层剑势时立即使用招式，还是再投入一个行动蓄满，取得下一次出剑的额外收益？

蓄满应该值得考虑，但不能成为每次战斗都必须遵循的最优顺序。敌人即将释放危险意图、现在可以击杀或需要抢先破盾时，提前花势也应合理。

## 3. 炼气道性：养锋

- 本场剑势从未满增长至当前上限时，获得一次“锋意”。当前原型上限为三层。
- 锋意是一次待兑现的强化标记，不是另一条需要积攒的资源条，最多保留一次。
- 停留在满势后继续剑击或守势，不反复触发；已有锋意时再次达到上限，也不叠加或补发。
- 下一次实际消耗剑势的主动攻击使用锋意，增加一次有限的剑伤；具体数值待定。
- 贯虹、破势与裂甲斩均可兑现，不只强化某一个借法技能。
- 额外剑伤建议遵循正常护盾抵挡规则，不默认穿盾、无视防御或触发额外行动。
- 锋意保留至本场兑现或战斗结束，不跨战斗储存；借道的道性本身仍持续本局。
- 细则建议：自动反击、持续伤害、用药及未消耗剑势的攻击不兑现锋意。

剑击和守势都能养锋，区别在于玩家选择以进攻还是防守蓄势，不要求先守后攻。没有锋意时，各招式仍遵循自身的普通使用条件。

## 4. 炼气主动技能：裂甲斩

- 暂议消耗两层剑势，占用本回合唯一主行动。
- 已认可破盾定位：先削减敌方一定护盾，再造成攻击伤害；无护盾或没有锋意时仍可使用。
- 细则建议：无护盾时不把额外削盾转为生命伤害。
- 普通攻击伤害建议低于贯虹，不具备打断意图的效果。
- 有锋意时，可正常兑现养锋的额外剑伤；没有锋意也能按普通效果使用。
- 具体伤害、削盾量及与注灵的交互未定，不直接写入正式配置。

职责分工：

| 操作 | 主要职责 |
| --- | --- |
| 剑击 | 进攻并积势 |
| 守势 | 防守并积势 |
| 贯虹 | 将剑势用于直接伤害 |
| 破势 | 将剑势用于应对可打断的危险意图 |
| 裂甲斩 | 将剑势用于攻击带盾敌人 |

## 5. 战术示例

- 当前两层剑势，敌人即将释放可打断的危险攻击：立即破势，不必为锋意承受攻击。
- 当前两层剑势，敌人处于低压力行动：可以剑击到三层获得锋意，再按下一回合敌情选择贯虹、破势或裂甲斩兑现。
- 蓄势时也可用守势，但要承担放弃该回合攻击的机会成本；不预设守势总是最优。

## 6. 后续拓展方向

以下仅是未来道韵或技能书设计方向，不代表已批准的强化项或永久解锁规则：

- 快攻：改善提前花势的收益，不让所有剑道构筑都只等满势。
- 蓄势：深化锋意的兑现效果，但避免无限叠层。
- 破甲：深化裂甲斩面对护盾的作用，不让它同时取代贯虹与破势。

## 7. 确认与验证边界

- “蓄满获得一次锋意、消耗剑势的攻击兑现”的核心循环已认可用于炼气阶段；接下来仍需讨论具体数字与未确认细则。
- 现有护盾在一次对应行动后清除，裂甲斩不能靠假定护盾永久存在来证明价值；需检验其能否在带盾回合提供有效的即时进攻选择。
- 检验额外等待一个行动的成本，不能只比较单次伤害。
- 检验现有藏锋、余势等强化与养锋的关系；不改写现有强化，也不默认养锋已经兼容所有后续机制。
- 不因本篇设计确认而改变四基础招式、增加灵力条、额外行动、技能槽位或正式借道数量。
- 若剑道长期不持剑时如何运作、锋意对未来其他剑道技能如何生效，需另行设计。
