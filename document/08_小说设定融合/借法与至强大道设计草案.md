# 借法与至强大道设计草案

日期：2026-11-05  
状态：讨论草案，未获整体确认，未实施。不修改小说源稿，不恢复旧卡牌战斗。  
素材来源：用户提供的十位至强截图，以及 `E:\创作\MoFaXunXian\总稿\设定总稿.md` 的“十位至强”与“纪元道韵”章节。

最新流程以[《忆境探索与局内借法规则》](忆境探索与局内借法规则.md)为准：局外先准备武器和物资，入境后随机确定两道、主动随机三选一取得一个，途中借法台继续构筑，主动最多三个、被动不限数量。本文的历史提案不覆盖该规则。

## 1. 已确认的起点

- 武器提供基础招式，功法提供流派。
- 借法借的是至强之道，从大道特征出发设计对局玩法。
- 忆境由历代至强的道构成，来源不限于黄金纪元十位至强。
- 每条道有丰富的跨境界技能，覆盖炼气至合道，不将每条道限制为一套少量技能。
- 少量入门道法可作为开局默认内容临时借用；其余技能必须通过忆境技能书实际带出才能永久解锁，局内拾取本身不解锁。
- 入境后在起始借法台随机确定两道与一个三选一主动，影响本局打法；局外不提前抽道，探索途中借法台可继续取得技能或兑换技能点，不在战前配齐整套。
- 主角是林澈，元君本源逐步找回后提供专属加成。
- 除明确标注已确认的内容外，以下层级、技能、数量及开放顺序均为建议，不因写入草案而自动确认。

## 2. 建议的设计层级

L02 后续已确认通用分工：大道负责本局规则，功法/传承归类技能与叙事，分支组织组合，境界限制承载上限，本源提供主角独有永久能力，首版不另加职业等级。下文具体流派和技能效果仍保留各自提案状态，最新本源与成长规则见《忆境探索与局内借法规则》第 27 节。

历代至强大道 → 传承功法或道法分支 → 各境界技能库 → 已带出技能书解锁的内容 → 本局借法配置。

- 大道决定规则特征，例如时间道关注效果何时生效，阵道关注行动如何排列。
- 功法是大道的具体运用方式，同一大道未来可以有不同流派，不将一位至强等同于唯一固定职业。
- 境界维度包含炼气、筑基、金丹、元婴、化神、炼虚、合道；已确认围绕核心机制与分支持续扩展，不要求每境界重做整套同数量技能。低阶技能跨境界仍可借用，具体分配见第 2.2 节。
- 武器基础招式仍负责基本攻防与资源经营，借法增加流派技能、被动或招式变化。
- 借法建议解释为调用自身能够承受的一部分道痕，而不是得到至强完整境界或召来本人代打。
- 默认入门道法只提供临时借用资格；其他技能的永久解锁需要对应技能书实际带出并消耗学习。S07 已确认首版书籍只解锁对应技能或术式版本，功法用于归类与叙事，不增加整道许可证购买门槛，见《忆境探索与局内借法规则》第 24 节。

### 2.1 技能书与使用资格的设计建议

探索忆境 → 获得技能书 → 实际带回局外 → 消耗一本对应书学习并永久收录 → 满足境界与本局候选条件后扩展随机借法资格（普通池规则见主规则第 19 节，S 组学习与收藏规则见第 24 节）。

- S04 已确认区分“已经收录”和“当前可借用”：高阶书可提前消耗收录，角色达到对应境界后才可进入合资格候选池，不因提前收录越阶使用。
- 角色晋升可以开放更高阶内容的使用范围，但不能自动获得没有带出技能书的技能。
- 技能书与其道痕来源、历史场景和遗藏品级建立合理的掉落关联；不意味着每局保底产书，也不把前期地图强行绑定到黄金十人。
- 技能库内容可以丰富，但单局主动最多装配三个、从本局两道逐步三选一获得；被动不设数量上限，以本局两道为主、偶尔混入通用被动，单次最多一个通用。主动满位可更换并继承旧技能强化等级，重复内容与交互边界仍待讨论。
- 各境界应增加新的组合与战斗选择，不只给同一技能递增伤害；已确认低阶技能保留候选资格，并通过随角色能力成长的基础效果与战术定位延续价值，具体效果和公式待设计。
- 技能书带出自动化实，不需手动转换；S01 已确认初学书消耗一本学习，进阶书沿用已定消耗。S05 已确认重复书保留出售，首版不做共鸣、碎片合成或重复书强化，不自动换局内技能点；具体售价仍待经济表。
- S03 已确认安全空间在失败时保住并实际带回的新技能书满足带出条件，可消耗学习；掉落丢失的书不能解锁。S06 已确认按忆境主题掉书，不完全绑定本局两道，首领提高稀有书机会但不保证指定技能；具体掉落表与概率另定。

### 2.2 已确认：核心分支、术式进阶与低阶保留

- 用户认可围绕大道核心机制与构筑分支扩展，不以每境界固定新增一套主动和被动支撑内容量。
- 基础威力成长、主动术式的技能书进阶、真正新技能与被动分别安排；晋升不自动解锁未带出的书，局内五次强化另计且不追加次数。
- 境界只限制使用上限，筑基仍可选择满足资格的炼气技能；同术式的跨境界形态在候选中合并为当前已解锁且合资格的版本，不重复占位。
- 被动不可强化，不推出每境界的同名数值升级版；新增内容应提供不同触发与取舍。
- 最新通用规则见《忆境探索与局内借法规则》第 11 节；剑道具体安排见《剑道技能体系与境界安排草案》，其中尚未认可的新名单与效果仍为讨论提案。

## 3. 十道的玩法方向

姓名与大道取自小说；“玩法方向”为游戏化提案，不是小说已有技能。

| 至强常用称呼 | 大道 | 建议玩法方向 |
| --- | --- | --- |
| 溯光时尊 | 时间 | 回响、延后生效、安排效果的触发时机 |
| 太虚界尊 | 空间 | 隔绝、封存与转移战斗效果；不依赖自由移动 |
| 青冥剑尊 | 剑 | 剑势经营、连贯出招、把握破势与决胜时机 |
| 幽冥魂尊 | 魂 | 魂痕积累、扰乱意图、针对特定行动制造破绽 |
| 玄黄地尊 | 土 | 筑御蓄守、护盾经营、将防守投入转为反击 |
| 澄浊元君 | 清浊 | 解析、承载、净化与转化为效果提案；L05 已确认作为主角本源专题、不入普通随机池，具体能力与上限另定 |
| 钧灵丹尊 | 丹 | 药性组合、疗愈、炼化，改变补给的使用收益与时机 |
| 经纬阵尊 | 阵 | 行动次序、阵纹组合、预先布局后触发 |
| 朔溟冰尊 | 冰 | 寒意积累、压制与凝滞危险招式，制造有限窗口 |
| 万锻体尊 | 体 | 主动锻体、承担风险后反攻，权衡生命与行动收益 |

设计约束建议：

- 不能把十道全部做成不同颜色的增伤，也不要求十道首版同时开放。
- 在固定站位回合制中表现其规则特点，不因空间道引入自由移动，不因阵道引入多人站位。
- 剑道可与铁剑契合，但其他大道也应有与铁剑组合的空间；不将大道直接锁成武器职业。
- 时间、魂、冰道需要区分触发方式与限制，不能都退化为无限跳过敌方回合。
- 战斗回响、炼化等不能凭空复制真实库存或产生可重复结算的物品。
- 丹道与体道不能成为无成本无限恢复，否则会消解跨战斗损耗。
- 不将人物完整历史、背叛真相或终局直接写成开局借法说明。

## 4. 同一把铁剑的示意

以下主要说明玩法差异；剑道炼气入门的已确认核心另见第 7.4 节及专项草案，具体数值仍未确定：

- 借剑道：围绕剑势的积累与释放安排出招，追求决胜窗口。
- 借土道：通过守势建立防御投入，再选择时机反击；与剑道的主动压制区分。
- 借阵道：按指定次序使用不同基础招式形成阵纹，牺牲即时收益换取后续触发。
- 借时间道：安排某次招式的有限回响，决定何时兑现；不等于获得完整额外回合或复制物品消耗。

已确认以自动生效的道性塑造打法、主动流派技能提供操作；最新明确主动最多装配三个、被动不限数量，逐步三选一获取。具体技能数值、候选规则与重复处理仍待确认。建议每个流派至少提供一个明确的战斗决策和一个可感知的专属操作，不仅堆叠被动数值。

## 5. 历史提案：入境前手动配置，已被替换

本节仅保留此前手动配置的历史提案，已被“开局只三选一取一个主动、局内逐步构筑”替代，不能据此实现战前配齐。最新流程见《忆境探索与局内借法规则》。

选择武器并查看基础招式 → 按大道和境界查看技能库 → 从已解锁且满足使用条件的内容中配置本局借法 → 查看最终技能与流派规则 → 按打法配置携入物资。

- 借法界面需要说明实际改变哪些操作、资源或触发条件，而不只展示至强尊号与背景。
- 功法收藏、借道权限和局内强化分别负责什么，需要进一步明确，不能将原型的强化解锁直接冒充正式借法。
- 局内强化可以深化已选流派，但这仍是提案，不预先确定候选池或改变现有强化。
- 未带出技能书的技能不因为选了对应大道就整条开放；境界提升也不能替代获取技能书。

## 6. 建议优先验证

- 可先挑剑、土、阵三个差异较明确、能利用现有基础招式的方向做设计验证，不代表已批准开发。
- L05 已确认清浊道不进入普通随机借道范围，作为元君本源找回专题独立设计、设明确上限，不自由复制全部至强技能；具体能力和节点仍待设计。
- 时间、空间等规则改动较大的大道，先明确可感知的玩法与约束，再决定实现顺序。
- 十位至强是本轮设计入口，不是所有遗藏锚点或历代至强的总数限制。
- 分阶段验证只限制近期制作范围，不将长期技能库压缩成每道少量技能，也不一次承诺完成所有大道、所有境界。

## 7. 借法演进与最新规则

### 7.1 历史方案

- 用户此前提出从所有道随机两道，战胜敌人后获得道韵加持、三选一强化技能。
- 后续已明确两道数量、主动最多三个与被动不限数量，并改为局内逐步获取；以第 7.6 节为准，不把历史表述当作新规则。

### 7.2 早期组合与强化建议

本节为历史讨论；与第 7.6 节冲突的部分以最新用户说明为准，不再自动在每场战后赠送原有形式的强化。

- 倾向让抽到的两道同时提供本局玩法方向，玩家可以逐步形成主辅或混合构筑，而不是自动解释为二选一。
- 历史建议曾将随机借道放在物资整备之前；用户最新确认入境后再抽，该旧顺序不再采用。
- 每道开局只提供有限的起始内容，不将整条道跨境界的全部技能一次性发给玩家。
- 战后候选建议围绕本局两道、已获得技能与武器基础招式生成，包含单道深化或两道联动；不强制每次固定各占一个候选。
- 例如剑道与土道组合，可设计剑势经营、防守收益或守后出剑等不同强化方向，具体技能名与数值未定。
- 道韵加持建议只在本局有效，不写成永久技能解锁，不替代技能书带出，也不直接提高角色境界。
- 道韵加持属于战斗构筑状态，不应凭空生成可出售或带回仓库的物品。
- 同局恢复已确认沿用两道、已生成的起始候选和已用重抽次数；结束探索不论是否战斗均须结算，成功或失败结算后新局可刷新。组合可玩性保障仍待明确，局外整备不抽道。

### 7.3 已确认：与技能书解锁的衔接

用户已认可将初始临时借用与技能书永久解锁分开。

每道预设少量开局可临时借用的入门道法；技能书负责永久扩展该道后续可用内容与高阶技能。

- 起始道法是技能书规则的有限例外，已获确认；具体道法、数量与强度尚未确定。
- 临时借到入门道法不意味着永久收录该道所有技能。
- 未带出的技能书不能因为本局抽到该道就永久解锁。
- 清浊道已由用户在 A1 明确排除出随机范围，不再作为普通随机候选。

### 7.4 已确认：道性与流派技能的分工

- 道性借道后自动生效、持续本局，不需要玩家点击；作为流派核心规则塑造打法。
- 道性需要明确触发条件、收益和限制，不以纯百分比增益替代核心玩法。
- 流派技能由玩家主动使用，与武器基础招式共用每回合一次主行动，不额外赠送行动次数。
- 技能使用独立技能栏，不放入斗法匣；斗法匣五格仅管理战斗物品。
- 未触发道性时，流派技能也应可正常使用；触发道性后获得特色收益，而非全部做成未满足前置就无法操作。
- 道性可与合适的基础招式及其他同道技能配合，不与唯一入门技能绑死，也不要求固定出招循环。
- 入门结构不自动限制所有境界的道性变化、技能数量或技能槽位。
- 此前“非攻击行动蓄一次强化”的养锋仅为分工示例，已由后续满势触发方案替代，不叠加使用。
- 用户已认可“养锋 + 裂甲斩”的核心方案作为炼气阶段剑道入门：蓄满三层剑势取得一次锋意，下一次消耗剑势的攻击兑现额外剑伤；锋意最多一次、不在满势时重复触发、战斗结束清除。裂甲斩提供主动破盾选择，与贯虹、破势分工。
- 具体记录见[《剑道入门设计草案》](剑道入门设计草案.md)。具体伤害、削盾量、暂议的两层消耗及未确认细则仍待讨论，未实施；这不是炼气全部技能，也不限制筑基及以上的剑道设计。
- 用户后续要求增加炼气技能、可以加入被动技能，并认可五主动、六被动的第一批剑道技能方向。“流派技能主动使用”说明的是主动招式的操作，不排斥另设可收集、可装配的被动；被动不自动等同借道自带的道性。具体内容见[《剑道炼气技能库草案》](剑道炼气技能库草案.md)，数值、未确认细则与装配规则仍待讨论。

### 7.5 仍可继续讨论的细化建议

以下仍为讨论方案，尚未确认，不作为正式随机数量、槽位、装配或解锁规则。

- 两道已确认入境后从当前版本参与随机的所有道中随机产生，彼此不同且排除清浊道；起始一次广告整组重抽、同局恢复不刷新与任意探索结算后新局可刷新已确认。已解锁内容如何扩展技能候选资格需明确，不再沿用战前自由手选配齐技能的建议。
- 两道共同提供候选来源，不强制主辅，玩家通过后续三选一自然形成侧重。
- 角色持有相同武器与抽到相同两道时，也可因已收录技能不同而形成不同的开局配置。
- 用户最新确认先在局外准备武器和物资，入境后才抽道；此前抽取结果在正式携入前可见的提案不再采用。先确定两道后才展示起始主动，同局恢复沿用结果；重抽与已确认结算刷新规则见《忆境探索与局内借法规则》第 2.1.1、2.1.2 节。
- 战后加持可分为数值深化、机制分支和双道联动，不要求每次固定各出一项，也不默认每次增加新技能按钮。
- 三个候选至少应有一项对当前配置立即有效，排除满级、缺失前置或完全没有适用对象的无效候选；不以此保证稀有候选。
- 强化已有技能不等于永久解锁新技能；用户已明确主动满位时可在借法选新技能后替换一个已有主动，并继承其强化等级。具体交互边界、同名重复与其他替换形式仍待讨论。
- 每道自身应能与武器基础招式形成可玩的循环，双道联动提供额外选择，不能要求抽中特定搭配才能正常战斗。
- 道韵加持倾向仅本局有效，技能书承担长期收集；两者在结算与界面上明确区分。
- S03 后续已确认安全空间在失败时保住并实际带回的新技能书满足带出条件，仍需消耗书学习，不因保住就自动解锁，见主规则第 24 节。

### 7.6 最新用户说明：地图借法台与逐步构筑

- 进入忆境后在起始借法台随机确定两道，再从两道主动技能中随机三个候选、选一个起始主动；局外整备不抽道，不一开始配齐技能。
