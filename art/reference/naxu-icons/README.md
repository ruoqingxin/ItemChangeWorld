## 交付规格

- 首批 12 枚：六档品质各两件，涵盖囊、匣、佩、葫芦、瓶、印、戒、镜、珠、鼎。
- 每枚独立 PNG，RGBA，最终尺寸严格为 112×112 像素，对应 2×2 个 56×56 格距。
- 现有格距由 54 像素格图加 2 像素间隔构成；图标画布仍按用户指定的 112×112 输出，不将格线画入图像。
- 四周至少留 8 像素透明安全边；主体最长边约 88–96 像素。戒指保留清楚的指孔，囊的束口、肩部和囊腹清晰分离。
- 采用现有物品的国风手绘、深色描边、简洁块面明暗与轻微旧化，不因像素尺寸要求改成像素画。
- 统一偏正面三分之四视角、左上方光源，主体居中、完整可见。粗轮廓和核心饰件在原尺寸下可辨。
- 真透明背景；不接受棋盘格假透明、白底、矩形色底、投影地面、场景或展示台。
- 图像内不带品质框、格线、文字、数字、容量、耐久、品质标志或水印。现有六张品质框由 UI 独立叠加。
- 品质以大轮廓、材质、主体结构、空间组件的连接方式共同体现；史诗为金色，传说为红色。去掉品质框、转灰度、关闭灵光后仍应能看出结构升级，此为出图目标，尚未完成图片验收。
- 所有档位采用相同绘制完成度与相近视觉尺度；普通器物造型简朴，不等于画得粗糙或刻意缩小。高品质不依赖增大主体或铺满光效。
- 关键特征在最终尺寸下应有约 8 像素以上，重要悬构间隙约 3 像素。灵光采用有界的实色细线和内缘亮边，避免抠图难以保留的薄雾、碎粒和发散光云。
- 可以另存高分辨率原稿，但不得用原稿尺寸冒充最终 112×112 交付。

## 出图后检查

1. 先不叠品质框，按六档并排检查轮廓和结构；再用灰度图、去灵光的观察方式检查是否仍能分档。重点对照普通/精良匣与优秀/史诗葫芦，先修正不符合项再导出。
2. 逐张检查 112×112 尺寸、真实 Alpha、透明安全边和主体完整性。
3. 在 112×112 原尺寸及 56×56 缩略尺寸下检查器型、戒孔、束口、提梁、盖口和悬构间隙辨识度；传说的核心不得缩成难以辨认的黑点。
4. 将图标放在现有六档品质框上预览，检查颜色冲突、边缘白晕与遮挡；品质框不烘焙进 PNG。
5. 全部通过后保存独立 PNG 与一张六档对照预览，并记录实际生成方式。
6. 如需接入运行时，再移入 `assets/ui/atlas/module/inventory`，新增独立 UUID，明确导入设置 `textureType: 2`、`sRGB: true`、`premultiplyAlpha: true`，同步真实引用与依赖表。

本次准备阶段没有替换现有图标、分配模板品质、修改容量、修改配置或变更存档。
