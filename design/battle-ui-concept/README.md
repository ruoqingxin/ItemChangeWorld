# 战斗界面概念稿

打开 `index.html` 即可查看 16:9 横屏战斗界面。界面按项目现有的水墨、沉墨绿、青玉与旧金视觉语言设计，可在浏览器中直接验证布局和交互。

## 设计重点

- 上方只保留地点、回合、敌方意图与暂停入口，建立战况层。
- 中央战区不被常驻面板遮挡，敌我体型与站位先于数值被看见。
- 下方将五个招式收进连续的做法栏，避免五张独立卡片争抢注意力。
- 选中招式后只展示一条即时说明和预期结果，降低每次决策需要读取的信息量。
- 敌方意图使用朱砂色独立强调，并与敌方状态签保持明确区隔。

## 可试交互

- 点击招式或按数字键 `1` 至 `5` 切换招式。
- 点击“施展”或按空格触发结算与敌方反击。
- 点击“防御”“用药”“结束回合”查看对应状态。
- 点击敌方意图签查看完整说明。

该版本是可交互的视觉原型，尚未替换 LayaAir 预制体和正式战斗绑定。确认视觉方向后，可按现有 `SkillBattleBattleView.lh` 与 `BattlePanel.ts` 的节点绑定方式接入正式界面。
